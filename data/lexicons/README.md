# Wiktionary headword index

`wiktionary_ja.json` is a modified extract of **Japanese Wiktionary contributors' data**, from the 2026-11-01 jawiktionary dump, extracted by Tatu Ylönen's Wiktextract and distributed by Kaikki.org. The source dump page and SHA-256 of the input gzip are recorded in the index. Individual original entries and contributor histories are available at `https://ja.wiktionary.org/wiki/<headword>`.

- [Japanese Wiktionary copyright and licensing](https://ja.wiktionary.org/wiki/Wiktionary:著作権)
- [Kaikki raw jawiktionary data and extraction details](https://kaikki.org/jawiktionary/rawdata.html)
- [Kaikki copyright and licensing information](https://kaikki.org/jawiktionary/index.html)
- [Wiktextract (Ylönen, 2022)](https://aclanthology.org/2022.lrec-1.140/)

The index has been changed by selecting Japanese headwords, limiting length and script, selecting noun/adjectival-noun and tagged idiom entries split by the current Sudachi Core configuration, coarsening tags, and deduplicating and sorting. Definitions and examples are not included.

This attribution and license notice covers the generated dictionary index. The source application and the project's separately maintained game rules are separate from that data file.
