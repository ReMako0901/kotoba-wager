このツリーでは旧盤面の部品・CSS・テストは削除済み。**git履歴から旧盤面ファイルを
復元して読むことは禁止**。読んでよいのは本書、`frontend/src/games/contract.ts`、

（入口 `FreshGamble.tsx` と自分の `games.css`）に閉じること。他のファイルは触らない。

## 世界観と設計の自由

- 画面全体は「革の手帳の開いたページ」。ゲーム部はそのページの上で行われる遊び。
- 構成・モチーフ・操作の形は実装者が新規に考案する。カジノの卓の模倣でも、
  見出し帯＋対戦エリア＋下部操作列という三段の定型でもないこと。
- 操作は物そのものに埋め込む（引く、めくる、選ぶ、振る、止める）。
- 数字や合計は、ページの余白に手書きメモのように置いてよい。

## 全種目共通

- 勝敗はサーバー側で確定済み。画面はそれを表示するだけ。再抽選や結果の改変はしない。
- **スキップ類は一切置かない**。結果が決まっている体なので、演出は最後まで再生する。
- 自動で進行しない。次へ進むのは常にプレイヤーの操作。ただしプレイヤーが開始した
  演出（カードの入れ替えなど）は、終わるまで再生してから次の操作を受け付ける。
- 勝率・強さ・変化量などの内部数値は表示しない。表示するのは種目名、遊びに必要な
  数字（カードの合計など）、結果の見出し（勝利／敗北／引き分け）だけ。
- 上部のアノマの写真と台詞の領域には何も被せない。写真をぼかさない。
- 画面は 393×681 CSS px で縦スクロールなしに収まること。横幅が広い画面でも崩れない。
- `prefers-reduced-motion` では激しい動きを短いフェードに落とす。
- 完了後の共通部品（全種目で同じ形でよい）:
  - 結果の見出し（勝利／敗北。バカラの引き分け継続中は引き分け）。
  - 「この結果を物語へ →」ボタン。`prepared` が false の間は押せず、スピナーと
    生成待ちの見た目（回る印＋金のインク線のきらめき）を見せる。`error` がある時は
    エラー文を見せ、ボタンは再試行できるよう押せる状態にする。
  - 生成待ち表示の汎用クラス `.generation-skeleton` / `.skeleton-ink` / `.spinner` の
    見た目も `games.css` に含めること（外側の画面でも使うため）。

## データの形（contract.ts と types.ts が正）

`gamble.kind` で種目が決まる。`gamble.outcome` は勝敗（未確定なら null）。
カードは `{ rank: 'A'|'2'..'10'|'J'|'Q'|'K', suit: '♠'|'♥'|'♦'|'♣' }`。
カードの絵札画像は `cards/<ランク><スート頭文字>.webp`（例: ランクA・スペードは
`AS.webp`、10・ハートは `10H.webp`。頭文字は ♠→S ♥→H ♦→D ♣→C）で
`frontend/public/cards/` に揃っている。スロットの絵柄画像は
`frontend/public/slot-symbols/` に bell.png / watermelon.png / bar.png / seven.png。

## 種目ごとの振る舞い

### じゃんけん（kind: 'rps'、サーバーへ手を送る）
- `gamble.moves` が試行の履歴。各試行は自分の手・相手（アノマ）の手・結果を持つ。
  手の番号は 0=グー、1=パー、2=チョキ。
- プレイヤーが手を選ぶと `onMove(現在の試行数, 手の番号)` を呼ぶ。
- あいこなら相手の手を見せたうえで、続けて次の手を選べる。勝敗が決まると
  `gamble.outcome` が入り、完了部品に移る。

### 一発サイコロ（kind: 'dice'、サーバーへ手を送る）
- 「振る」操作で `onMove(0)` を呼ぶ。結果は `moves[0]` の目（1〜6）と勝敗。
- 目はサイコロの面として描く（点の配置は通常のサイコロと同じ）。

### カード当て（kind: 'card_guess'、サーバーへ手を送る）
- `gamble.cards` は3枚、`gamble.target` は当たりのカードの番号（cards の並びでの位置）、
  `gamble.swaps` は入れ替え手順（位置0・1・2のうち2位置の組の列）。
- 流れ: ①最初は当たりのカードだけ表向きで見える。②プレイヤーが開始の操作をすると
  全て裏返り、手順の順に2枚ずつ位置が入れ替わる演出が最後まで再生される。
  ③プレイヤーが位置（左・中央・右）を選ぶと `onMove(0, 位置番号)` を呼ぶ。
  ④結果では当たりのカードと、選んだ位置のカードが表向きになる。

### スロット（kind: 'slot'、画面内で完結。onMove は使わない）
- `gamble.reels` は3つの絵柄名（ベル／スイカ／REG／BIG）。絵柄画像との対応は
  ベル=bell.png、スイカ=watermelon.png、REG=bar.png、BIG=seven.png。
- レバーを引くと3リールが回り始める。各リールに対応する止める操作があり、
  プレイヤーが1つずつ止める。止まったリールには確定した絵柄が出る。
- 3つ全て止まったら `gamble.outcome` で勝敗を見出し、完了部品に移る。

### ブラックジャック（kind: 'blackjack'、画面内で完結。onMove は使わない）
- `gamble.rounds` は1件だけ。その中の `player` が自分の手札の最終形、
  `banker` がアノマ（ディーラー）の手札の最終形、`dealer_hands` は
  「自分のヒット回数ごとに、その時点で見せてよいディーラーの手札」の列。
- 開始時、自分の札は2枚見えている。HIT のたびに次の1枚が加わる。
  合計は A を 1 または 11、絵札を 10 として 21 を超えない最大値。
- HIT できるのは、まだ加わる札があり、合計が 21 未満のときだけ。
  STAND するか、合計が 21 以上になったら終了。終了時にディーラーの札は
  全て表向きになり（開始時は1枚だけ表）、勝敗は `gamble.outcome`。
- ディーラーの見せ札は `dealer_hands[ヒット回数]` を使い、無ければ `banker` を使う。

### バカラ（kind: 'baccarat'、画面内で完結。onMove は使わない）
- `gamble.rounds` は複数件あり得る。各ラウンドに `player` と `banker` の手札
  （各2〜3枚）と、そのラウンドの結果（win/loss/tie）がある。
- 合計は各札を A=1、2〜9=そのまま、10と絵札=0 として合計の下1桁。
- 流れ: 札を1枚選ぶと大きく表示され、「絞り」で開ける。絞りは札の端を
  ドラッグ（または矢印キー）して裏を少しずつめくり、ほぼ全面が見えたら表になる。
  「表にする」ボタンでも開けてよい。両者とも最初の2枚が開くと、3枚目がある側は
  3枚目が配られて同じように開ける。バンカー側には全てまとめて開く操作も置く。
- 全ての札が開くとラウンド確定。引き分けなら「同じことばでもう一度」で
  次のラウンドへ。勝敗が決まったラウンドでは完了部品に移る。
