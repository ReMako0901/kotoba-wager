# 実プレイFB第7弾（2026-11-27）

ユーザーの実プレイ所見への対応。

## 1. じゃんけんの掛け声と札が重ならないように

- 掛け声（じゃん・けん・ぽん）の文字が自分の札に被って読みにくい。
- 順序で解く: 掛け声の間は札を出さない（盤面中央は掛け声だけ）。
  掛け声が終わってからアノマの札→あなたの札が現れる。中央表示は維持。

## 2. 結果確定後の長いパネルを廃止

- 「この結果を物語へ」が入っている長い四角いパネル（生成待ち表示の
  枠ごと）を消す。ボタンだけを残す（結果画面の「次は何をねらう？」と
  同じようにボタン単体で置く）。生成中であることは原稿側の表現
  （シマー等、既存の待ち表現）に任せ、パネルは作らない。

## 3. 差分の傍線を一繋がりに

- 変わった文字の横の傍線が文字ごとにブツブツ分かれている。
  連続した変更範囲（ラン）ごとに、切れ目のない1本の縦線にする。
  色・位置（朱の細線）の意匠はそのまま。

## 4. カード当て: シャッフルを約5秒・最初から速く

- 現行でも簡単すぎる。入れ替え全体を約5秒にし、最初から速い速度で
  入る（緩急の山は小さく）。14回＋山場の同時入れ替えは維持。
- 右上の「左の札を開いた」のような状態テキストは削除する。

## 5. チンチロ: 「アノマのターンです」を先に1秒見せる

- 表示と同時にサイコロが動いてしまっている。キャプションを約1秒
  表示してから、彼女のロールを開始する。

## 6. スロット: レバーのナビ表示

- レバーの下に「↓ 引いてスタート」の小さなナビを出す（矢印＋短い文）。
  引いたら消える。

## 7. エンディング遷移の作り直し（到達の見せ方）

※初稿からユーザーの追加指示で変更（2026-11-27 14:19）。こちらが正。

- 現在の到達画面（脱出する／さらに賭ける＋集計パネルの専用画面）は
  廃止する。到達した回も結果画面はいつも通り。
- 到達した回の結果画面では、進む操作のところに最後の二択を出す:
  「脱出する」「まだ続ける」。
- 「脱出する」→ 画面が暗転してエンディングに入る。エンディングは
  オープニングと同じ作り: 黒画面にアノマの顔のドアップが大きく出て、
  集計（総勝負回数・獲得数・喪失数・差分）とエンディング台詞を
  タップ送り（画面全体タップ）で表示し、最後のタップでタイトルへ。
  エンディングの中身（台詞）はまだ未定なので、現行の到達台詞
  （差分の符号で分岐。ただし最終文が開始文より短い場合は「増えた」
  前提の台詞を使わず neutral）をそのまま流用する。
- 「まだ続ける」→ アノマの台詞「あら、もう帰っていいのに。物好きね。」
  を表示して、通常通り次のラウンドへ進む。
- 続行した後は、結果画面の左側に「脱出する」ボタンを常時付ける
  （右側の「次は何をねらう？」と対になる位置）。押せばいつでも
  上記の暗転エンディングへ入る。
- 二択（脱出する／まだ続ける）が出るのは初回到達の1回だけ。
  2回目以降は二択を出さず、左の「脱出する」ボタンだけにする。
- バックエンドの到達記録・集計はそのまま使う。story-choice は
  従来通り呼んでよい（脱出／続行の記録）。
