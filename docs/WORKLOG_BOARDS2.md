# 盤面第2弾の作業メモ

対象は FreshGamble の3種目と games.css。初期差分は未追跡の盤面仕様書のみ。勝敗と配札列は既存データを使い、公開・コミットは行わない。ブラウザ撮影は Muse 担当。

スロットは停止操作時の帯の位置から次の同一絵柄へ減速し、全リール着地で結果表示。BJ はサーバーの dealer_hands[hits] を優先し、初期4枚・ヒット・親の公開を順に進める。依存のオフラインインストールでキャッシュ不足が発生し、ロックファイルが一致する隣接ツリーからローカル依存を用意。

バカラは開始端と軸を固定して符号付き移動量で開閉し、75%で確定。矢印キーでも開閉可能。バンカー一括操作は既存仕様に従い、すでに場に出ている札だけを対象にする。3枚目を両者が引く場合はプレイヤーの3枚目を開いてからバンカーに配る。

最終検証は node --test frontend/tests/*.test.cjs が11ファイルすべて成功し、frontend の npm run build（tsc -b と Vite）および git diff --check も成功。既存テストの変更なし。コンポーネントハーネスで、リール別の停止位置・3本着地前の結果抑止、BJの交互配札・ヒット後の親合計、バカラ四方向の往復ドラッグ・3枚目の順序を追加で確認した。ハーネスのリール計測と着地イベントは模擬。

Muse 引き継ぎ：393×681での収まり・肖像との位置関係、リールの減速、配札・めくりの見え方、reduced-motion のフェードをブラウザで目視・撮影する。ブラウザ実測、pytest、Firestore エミュレータ、実 Gemini、公開配信確認は未実施。
