# UI仕上げ：絞りのアニメーションヒントとアノマの基礎アニメーション

UI_REDESIGN（Phase A・B）の続編。ユーザーの夜通し作業の指示
（2026-11-18）に基づく仕上げ。原則は変わらない：説明は文字で
なくUIとアニメーションで、メタ要素は出さない。

## 1. バカラの絞りヒントをアニメーションにする

- BaccaratCard の可視テキスト「上下左右にスワイプして絞る」を消す
  （aria-label の読み上げ説明は残す）
- 代わりに、まだ開いていない絞り対象のカードへ、角がわずかに
  めくれ上がるような控えめなアニメーションを繰り返し付ける
  （絞る操作ができることと方向を動きで示す）。開いたら止める
- prefers-reduced-motion では動かさない

## 2. ステージのアノマに基礎アニメーション

### 呼吸のような揺れ

- ステージのポートレート全体に、ごく緩やかな揺れ（上下の
  微移動と 1.0〜1.015 程度の拡縮、約6秒周期の往復）を付ける
- 表情クロスフェード（画像側）と競合しないよう、揺れは
  ポートレートの外側ラッパーに付ける
- prefers-reduced-motion では止める

### 瞬き

- 素材：`frontend/public/anoma/<表情ID>-closed.webp`（目を閉じた
  版。Muse が別途用意する。無い表情もある前提で実装する）
- ステージ表示中、2.8〜5.5秒のランダムな間隔で、約130ms だけ
  閉じた版に切り替える
- 表情が変わった直後（クロスフェード中）は瞬きしない
- 閉じた版の読み込みに失敗した表情では瞬きを無効にする
  （エラー表示や壊れた画像を出さない）
- prefers-reduced-motion では瞬きしない

## 含まないもの

口パク、表情以外のポーズ変更、確率・抽選・保存・台詞の変更、
バックエンドの変更。
