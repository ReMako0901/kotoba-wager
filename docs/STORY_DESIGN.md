# 『言葉の魔女 アノマ』ストーリー・世界観実装仕様書  
Version 1.0  
## 1. 作品概要  
## 基本設定  
プレイヤーは、謎の女性「アノマ」に捕らえられ、言葉を賭けるギャンブルに参加させられる。  
アノマは「言葉の魔女」と呼ばれる存在。  
人間の言葉や記憶を操作する能力を持ち、人間が自分の大切な言葉を失ったり、別の意味に書き換えられたりする様子を娯楽として楽しんでいる。  
プレイヤーは6種類のギャンブルを通じて、言葉を獲得・喪失・改変されながら、脱出を目指す。  
規定回数の勝負を終えると脱出する権利が得られるが、そのまま追加のギャンブルを続けることもできる。  
## 作品の中心テーマ  
**「言葉の数値的な価値と、人間にとっての主観的な価値の非対称性」**  
一般的なギャンブルでは金銭を賭け、勝敗も金銭的な損益で評価できる。  
本作では「言葉」を賭ける。  
言葉は1個、2個と数えられるが、それぞれの言葉が持つ価値は人によって異なる。  
例えば、大切な思い出の詰まった言葉を一つ失った人にとって、別の言葉を十個獲得しても、その喪失が埋まるとは限らない。  
本作では、この価値観のズレをゲーム体験によって提示する。  
  
## 2. アノマのキャラクター設定  
**名前：** アノマ（ANOMA）  
**異名：** 言葉の魔女  
**外見：** 年齢不詳の妖艶な女性。白黒の容姿。片目の瞳に漢字が浮かぶ。胸元には「アノマ」と書かれた、取り消し線付きの名札を付けている。  
## 人格  
* 上品で余裕のある話し方。  
* 人間を観察することを楽しんでいる。  
* ギャンブルの勝敗そのものにも興味がある。  
* 言葉の意味を改変することを娯楽とする。  
* 人間にとっての言葉の主観的価値を理解していないように振る舞う。  
* 言葉の価値を個数で評価する。  
* 人間に対して敵意をむき出しにすることは少ない。  
* プレイヤーが言葉を失っても、当然のように次の勝負を勧める。  
## 最重要設定  
**アノマは、言葉の個数にしか興味がない。**  
例えば、  
* 10個獲得、9個喪失：プラス1  
* 1個獲得、0個喪失：プラス1  
アノマにとって、この二つは同じ成果である。  
人間が言葉に抱く感情や記憶を、アノマは数字の評価に反映しない。  
この性格はゲーム中の台詞、演出、エンディングすべてに一貫して反映する。  
  
## 3. 世界観と導入  
## 舞台  
白を基調とした、現実から切り離された空間。  
原稿用紙を思わせるシンプルな世界。  
黒い文字、線、余白で構成されている。  
アノマはこの空間でプレイヤーを待っている。  
## オープニングシナリオ案  
目を覚ますと、目の前には真っ白な空間が広がっていた。  
そこには、黒髪の女性が一人。  
女性はあなたを見つめ、静かに微笑む。  
**アノマ：**  
（挨拶は次の5つからランダムで1つ）  
「あら、目が覚めたのね。」  
「やっと目を覚ましたのね。」  
「こんにちは。目が覚めたのね。」  
「おはよう。目が覚めたのね。」  
「ごきげんよう。目が覚めたのね。」  
「私の名前はアノマ。言葉をつかさどる魔女よ。」  
「ここではあなたにちょっとしたお遊びに参加してもらうわ。」  
「勝てば新しい表現が手に入る。負ければかけた言葉が文脈から消失する。」  
「私が満足したら帰してあげる。」  
「めちゃくちゃにされるのが怖い？なら、勝ち続ければいいじゃない。」  
「なんで自分が…って？あなた、面白い顔してるもん。」  
ここでゲーム本編へ移行する。  
  
## 4. ギャンブルの基本構造  
既存の6種類のギャンブルを使用する。  
1. じゃんけん  
2. 3枚カード当て  
3. サイコロ  
4. スロット  
5. ブラックジャック  
6. バカラ  
各ゲームのルール、抽選処理、勝敗判定は既存実装を維持する。  
## 賭ける言葉  
以下の2方式を使用する。  
* プリセット文章：約100種類から自由に選択  
* 自由入力：20文字以上100文字以内  
勝敗によって、言葉の獲得・喪失・意味の改変が発生する。  
言葉の変化は既存のゲーム仕様を使用する。  
## アノマの反応  
言葉獲得時：  
「一つ増えたわね。よかったじゃない。」  
言葉喪失時：  
「あら、一つ減っちゃったわね。でも、次に勝てばいいでしょう？」  
意味改変時：  
「ふふっ。少し意味が変わっただけよ。」  
複数回勝利時：  
「ずいぶん増えたじゃない。もっと増やしてみる？」  
複数回敗北時：  
「減ってばかりね。でも、まだ言葉は残っているでしょう？」  
台詞は複数用意し、同じ反応が連続しにくいようにする。  
  
## 5. ゲーム進行と物語構造  
## 第1段階：強制参加  
プレイヤーはアノマのゲームに参加する。  
規定回数に達するまでは脱出できない。  
この期間は、アノマの人格とゲームルールを理解する導入を兼ねる。  
## 第2段階：脱出権の獲得  
規定回数の勝負を終えると、脱出可能になる。  
アノマは獲得数と喪失数を集計する。  
ここでプレイヤーに選択肢を提示する。  
* 脱出する  
* さらに賭ける  
ゲームを終了する操作が別に存在する場合は、その機能を維持する。  
## 第3段階：任意の延長戦  
脱出できる状態で、あえて勝負を続ける。  
この段階では、プレイヤー自身がリスクを選択する。  
アノマは継続を歓迎する。  
「帰れるのに、まだ遊ぶの？」  
「ふふっ。いいわよ。私はいつまでも付き合ってあげる。」  
延長戦でも言葉の増減・改変を記録する。  
延長戦の累計回数などを利用して、エンディング分岐や追加台詞を発生させられる構造にする。  
  
## 6. エンディング構成  
複数のエンディングを想定する。  
## A. ノーマルエンディング【基本採用】  
**条件：** 規定回数終了後、脱出を選択。  
アノマがプレイヤーの結果を集計する。  
評価対象は言葉の獲得数、喪失数、最終差分。  
**言葉が増加した場合**  
「今回は言葉がたくさん増えたじゃない。」  
「よかったわね。」  
「また遊びにいらっしゃい。」  
**言葉が減少した場合**  
「今回は少し減っちゃったわね。」  
「でも、これしか減らなかったんだからよかったじゃない。」  
「また次に増やせばいいのよ。」  
**増減数が0の場合**  
「増えた数と減った数が同じね。」  
「つまり、何も変わらなかったってことじゃない。」  
「ふふっ。次はもう少し頑張ってみたら？」  
**演出上の重要事項：**  
プレイヤーがどれほど大切な言葉を失っていても、アノマは数字だけで評価する。  
この価値観のズレを説明台詞ではなく、自然な会話によって表現する。  
## B. バッドエンディング【構想段階】  
**方向性：** 延長戦によって、プレイヤーが大切な言葉を失い続ける。  
十分に脱出できる機会があったにもかかわらず、賭け続けたことが結末につながる。  
アノマは言葉が大幅に減ったことだけを気にする。  
「ずいぶん減っちゃったわね。」  
「でも、最初からやり直せば、また増やせるわよ。」  
本人にとって取り返しのつかない喪失であっても、アノマは同じ態度を崩さない。  
具体的な発生条件は未確定。  
## C. グッドエンディング【構想段階】  
**方向性：** 言葉の価値を考え、自分の意思で賭けを終える。  
単純な獲得数によってグッドエンディングを決めない。  
例えば、言葉の数が減っていても、自分にとって大切なものを守る選択をしたプレイヤーには、肯定的な結末が成立し得る。  
アノマはその選択を完全には理解できない。  
「もっと増やせるかもしれないのに、もういいの？」  
この価値観の違いを結末に反映する。  
具体的な発生条件は未確定。  
## D. トゥルーエンディング【構想段階】  
**方向性：** アノマという存在に対する認識が変化する。  
通常のプレイ中、アノマは人間の言葉を弄ぶ娯楽的な存在として描かれる。  
しかし、特別なエンディングに到達すると、アノマの言動や価値観について新しい解釈が生まれる。  
重要なのは、これまでのアノマの人格を否定しないこと。  
**アノマの過去、正体、真の目的は現時点では未確定。**  
かつて人間だった等の設定を確定情報として実装しない。  
現段階では真エンディングへの分岐枠のみ用意する。  
  
## 7. アノマの演出と物語の連動  
キャラクター画像の瞳に表示する漢字を、ゲーム状態に応じて変える。  

| 状態    | 瞳の文字    |
| ----- | ------- |
| 通常    | 言       |
| 言葉獲得  | 得・増・生・添 |
| 言葉喪失  | 失・欠・亡・消 |
| 大きな改変 | 歪・変・無など |
| 賭博継続  | 続・賭     |
| 脱出    | 帰・終     |
  
通常は片目にのみ表示。  
重大な改変や特殊なイベントでは、両目に漢字が出現し、グリッチ演出を使用する。  
通常の勝敗時は、対応する文字群からランダムに選択する。  
アノマの名札には「アノマ」と書かれており、その文字は一本の横線で取り消されている。  
  
## 8. 記録するデータ  
ストーリーとエンディングで、最低限以下を参照できるようにする。  
* 総勝負回数  
* ギャンブルごとの勝敗  
* 獲得した言葉の数  
* 失った言葉の数  
* 最終的な増減数  
* 改変された言葉と改変結果  
* 規定回数到達時点の状態  
* 延長戦の回数  
* 脱出・継続の選択  
研究目的の分析に利用できるよう、言葉の数量的な変化と、ゲームの進行履歴を関連付ける。  
既存の記録機構があれば流用する。  
  
## 9. 実装指示（Muse / Codex向け）  
この仕様書を、言葉ギャンブルゲームのストーリーおよびキャラクター設定の基準とする。  
## 最優先で実装するもの  
1. アノマの人格と台詞の管理  
2. オープニングシナリオ  
3. 規定回数到達時の脱出・継続選択  
4. 獲得数・喪失数・差分を利用するノーマルエンディング  
5. 各ギャンブル共通の台詞イベント  
## 後続フェーズ  
1. 延長戦専用の台詞  
2. バッドエンディングの条件と演出  
3. グッドエンディングの条件と演出  
4. トゥルーエンディングのストーリー  
5. アノマの表情・瞳文字・アニメーションとの完全統合  
## 開発上の条件  
* 既存のゲームルールや勝敗判定を変更しない。  
* 既存のプリセット文章や自由入力機能を維持する。  
* エンディングの条件は設定データとして管理し、後から調整できるようにする。  
* 台詞をソースコードに大量に直接埋め込まず、専用のシナリオデータとして管理する。  
* キャラクターアニメーションが未完成でもストーリーを実行できるようにする。  
* 未確定のストーリー設定を独断で確定しない。  
* 既存の実装と仕様が衝突する場合は、現状を調査して報告する。  
* 各段階でテストを行い、実装内容を報告する。  
## 最初に行う作業  
まずリポジトリ内の既存ストーリー、ゲーム進行、エンディング処理、記録処理を調査する。  
その結果をもとに、実装フェーズと変更予定ファイルを整理する。  
すでに実装されている機能は再実装しない。  
現時点では、確定しているオープニング・アノマの基本台詞・ノーマルエンディングを優先し、未確定の分岐は拡張可能な構造として準備する。  
  
## 10. 制作上の最重要原則  
**アノマは言葉を数で評価する。人間は言葉に意味を見いだす。**  
この認識のズレが作品全体の中心である。  
ストーリー、台詞、UI、エンディング、アニメーションのすべてで、この原則を一貫させること。
