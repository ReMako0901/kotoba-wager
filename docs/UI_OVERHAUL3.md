# UI再構成（第3ラウンド）：アノマ全面＋原稿は手元の物

第2ラウンド（暗い舞台＋白い原稿）へのユーザーの評価：
「これでもまだ既存の枠に治ってる」。変わったのは世界観と
装丁で、画面の文法（上の帯＋中央の紙＋下のバー、モーダル、
画面ごとの遷移）が残った。今回はユーザーが方向を指定した。

## コンセプト（固定）

**アノマを全面に大きく置き、原稿は彼女の手元にある物として
重ねる。**

- 画面の地はアノマ本人。肖像が画面いっぱいの最下層にいて、
  顔が見える大きさ・位置で常駐する（帯に縮めたタイルでは
  ない）
- 原稿用紙は、彼女の手元に置かれた実物の紙として前景に
  重なる。影と縁を持ち、画面の部品ではなく「物」として
  見えること
- 台詞は彼女の場面の上に重なる（帯で領域を割らない）。
  画像の上でも読めるよう、半透明の地や影で可読性を担保する
- 操作要素は紙の縁や場面の中の物として置く。画面下に
  独立した固定バーは作らない
- 物語選びは本の物として、ギャンブルは卓上の物（札・賽・
  盤）として、同じ場面の上に重ねる
- 画面遷移は場面の切り替えではなく、物の出し入れ・移動で
  つなぐことを基本とする

## 禁止（前ラウンドの文法）

- ステージ帯（小さい肖像タイル＋台詞カードの横帯）
- 固定アクションバー（画面下の独立した帯）
- 既定の手段としてのモーダル被せ（選択やギャンブル選択を
  画面全体のダイアログで覆う形）。物として場面に重なる
  形に置き換える
- ナビ＋メタ＋メイン＋バーの行分割レイアウト
