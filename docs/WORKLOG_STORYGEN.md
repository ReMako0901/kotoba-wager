# 質問から始める物語
仕様は STORY_GENERATION.md。既存の custom_text と解析、Gemini 呼び出し、日次枠、ダイアログ板を利用する。このツリーのセッション保存はローカル JSON。生成記録のみ Firestore を用いる。ブラウザ撮影・公開は Muse 担当。

## 実装済み
- OP後に名前＋7候補から重複なしの2問。10文字未満では各問1回だけ深掘り。最初の入力を名前として保持し、深掘りは answers に追記。
- 生成後に既存解析で確認し、不足時は再生成1回、予備文は名前入りの導入と固定本文。各 Gemini 呼び出し前に既存の日次枠を予約。
- Firestore の generated_stories に回答と作品、サーバー時刻を保存。保存エラーは503。カスタムセッションに生成IDを保持。セッション開始のみ失敗した場合、同じ回答で再送すると生成結果・開始IDを再利用する。

## 質問画面の文言
- まず、あなたのことを教えてくれる？
- 内緒のことや重い話は、ここではお休みにしよう。
- 物語では、あなたを何と呼べばいい？
- 今日はどんなことがあったの？／どこから、どうやって来たの？／今はどんな気分？／どんなものが好き？／今日は何を食べたの？／最近、気になっていることはある？／どこへ行ってみたい？
- もう少しだけ、教えてくれる？
- 住所・学校・連絡先など個人が分かることや、重い話題は避けてください。
- 連絡先を除いて答えてください。
- 答える／プリセットの文で始める
