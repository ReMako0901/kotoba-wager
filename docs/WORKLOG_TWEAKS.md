# 追加UI指示の作業メモ

前回の退場コピー・画面キーを維持する。言葉選択は既存の規定数到達判定に一本化。喪失は LossManuscript の確定済み取引の表示で、選択位置の文字を粉砕し、紙のクリップ外にある写真へ送る。自動表示テスト中の手動ボタンクリックも現仕様に合わせる。コミット・公開は行わない。

ボタン削除と自動再表示テストの更新が完了。LossManuscript の旧落下演出を、選択字形を分割して写真の実測中心へ運ぶ表示に置換。軽減時は文字単位のフェード。表示コピーは操作を受けず、画面離脱時に破棄する。次は型検査・既存テスト・ビルド。
