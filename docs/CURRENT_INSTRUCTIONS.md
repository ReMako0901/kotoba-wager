# 現在の作業指示

このファイルは、Codex（実装担当）への **現在の指示の入口**。Muse
（企画・仕様担当）が方針の決定・変更のたびに更新して push する。
ユーザーがチャットで指示文を貼る運用はしない。

## Codex への決め事

- 作業を始める前に、必ず `main` を pull してこのファイルを確認する
- ここに書かれた指示書・仕様書を読み、その範囲だけを実装する
- 完了・中断したら、このファイルの「状態」を実態に合わせて更新し、
  詳細は `docs/STATUS.md` と `docs/CHANGELOG.md` に残す
- ここに無い作業は始めない。必要だと思ったら、勝手に広げず報告する
