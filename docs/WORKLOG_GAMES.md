## 2. 世界観とUI設計の判断
- **「革の手帳の開いたページ」の上の遊び**:
  - カジノ卓の模倣や「上部見出し帯＋中央対戦エリア＋下部操作列」の三段定型を排し、手帳の罫線ページの上に置かれた紙片・活版カード・象牙の賽・真鍮の覗き窓・栞リボンとして構成した。
  - 種目名はページ左端に差し込まれた縦書きの耳紙タグ（`.folio-ear-tag`）として配置し、縦の高さを圧迫しないレイアウトにした。
  - 操作はすべて「物そのもの」に埋め込んだ（活版紙札自体を抜く、八角皿の上のサイコロに触れて振る、封蝋帯を解いて3枚のカードそのものを抜く、覗き窓の右脇から突き出た真鍮の引き手を引いて各窓の留め金で止める、山札そのものを引いて赤い栞リボンで勝負する、ルーペ台紙の上の札の端をドラッグ／矢印キーで絞ってめくる）。
  - 勝率・強さ・変化量などの内部数値は一切表示せず、スキップボタン類も一切置いていない。
  - 上部のアノマ写真・台詞領域には何も被せず、写真もぼかさない。
  - 393×681 CSS px の画面（ゲーム部に使える高さ約 480px）で縦スクロールなしに収まるよう、`max-height: 476px` と柔軟な余白・カード寸法（`clamp()`）で設計した。

## 3. 種目別の実装詳細
1. **じゃんけん (`rps`)**
   - `gamble.moves`（`HandMove[]`）を参照し、手（`0`=グー、`1`=パー、`2`=チョキ）の活版札をタップすると `onMove(moves.length, handId)` を呼ぶ。
   - アノマの出した手は左上の付箋札に、これまでの試行履歴は余白の手書き風メモに表示。あいこ（`outcome === 'tie'` かつ `gamble.outcome === null`）のときは相手の手を見せたまま次の手を選べる。
2. **一発サイコロ (`dice`)**
   - 八角の賽皿（`.folio-dice-tray`）をタップすると `onMove(0)` を呼ぶ。
   - `moves[0]` 到着後、転がり演出を経て `moves[0].face`（1〜6、3×3グリッドの標準ピップ配置、1は朱色の大星）を表示し、完了部品へ移行する。
3. **カード当て (`card_guess`)**
   - ①初期状態（`reveal`）では `gamble.target` の位置のカードのみ表向きで表示。
   - ②「札を伏せて混ぜる」（`.folio-wax-ribbon`）を押すと全札が裏返り、`gamble.swaps` の手順通りに2枚ずつ水平位置（`translate3d`）を入れ替えるアニメーションを最後まで再生（再生中は操作ロック、スキップなし）。
   - ③再生完了後（`choose`）、左(`0`)・中央(`1`)・右(`2`)のカードそのものをタップすると `onMove(0, 位置番号)` を呼ぶ。
   - ④結果確定時（`done`）は当たりのカードと選んだ位置のカードを表向きにして完了部品を表示。
4. **スロット (`slot`)**
   - 右側面の真鍮レバー（`.folio-slot-lever`）を引くと3つのリール窓が回転開始。
   - 各リール窓（`.folio-reel-window`）をタップして1つずつ止めると、`gamble.reels[i]`（ベル=`bell.png`、スイカ=`watermelon.png`、REG=`bar.png`、BIG=`seven.png`）が表示される。
   - 3つすべて止まると `gamble.outcome` の結果見出しと完了部品を表示。
5. **ブラックジャック (`blackjack`)**
   - `gamble.rounds[0]` を使用。左上余白にアノマ（親）の手札と合計メモ、右下に自分の手札と合計メモ、中央対角に「山札を引く (HIT)」と「この手で勝負 (STAND)」の栞リボンを配置。
   - 開始時は自分の札2枚とディーラーの1枚目のみ表向き。ディーラーの手札は `dealer_hands[hits] ?? banker` を参照。
   - HIT は `2 + hits < player.length` かつ `playerTotal < 21` のときのみ可能。STAND するか `playerTotal >= 21` になると終了し、ディーラーの全札が表向きになって完了部品を表示。
6. **バカラ (`baccarat`)**
   - `gamble.rounds` の複数ラウンドに対応。合計は A=1, 2〜9=そのまま, 10/絵札=0 の合計の下1桁。
   - 最初は PLAYER / BANKER とも最初の2枚ずつが裏向きで配られる。未公開の札を選ぶと下段の「絞り台」に大きく置かれ、端のドラッグ（Pointer Events）または矢印キーで裏紙が少しずつめくれ、75%以上めくれると表になる。「表にする」ボタンでも即座に開ける。
   - BANKER 側には「バンカーをまとめて開く」ボタンも設置。
   - 両者の最初の2枚（計4枚）がすべて開くと、3枚目がある側には3枚目が配られて同様に開ける。
   - 全札が開くとラウンド確定。引き分けで次ラウンドがある場合は見出し「引き分け」と「同じことばでもう一度」ボタンで次ラウンドへ進行し、勝敗確定ラウンドでは完了部品を表示。
