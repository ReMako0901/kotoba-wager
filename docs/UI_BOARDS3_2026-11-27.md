# 2026-11-27 盤面第3弾（ユーザー実機FB、スクショ3枚付き）

対象は初心者3種（じゃんけん／カード当て／チンチロ）。

## じゃんけん（フロントのみ）

- 勝敗が分かりにくい。手を選んだら、結果を出す前に
  「じゃん」「けん」「ぽん」の三段のアニメーションを入れる。
  3つの言葉が順にパッと出る（少しずつ大きく／勢いよく）。
- その後に両者の手がパッと表示され、勝敗を大きめに表示する。
- あいこのときは「あいこで、しょ」の感じで表示して、次の手の選択へ続く。
  あいこのたびに同じ三段アニメーションを繰り返してよい。
- 既存の記録表示（余白の記録）は残してよいが、勝敗の主表示は新しく大きく出す方にする。

## カード当て（バックエンド＋フロント）

- 当たり札を **A♠（スペードのエース）固定** にする。3枚は A♠＋他の2枚で構成し、
  A♠の初期位置は今まで通りランダム。シャッフルと当ての仕組みは変えない。
  backend/app/gambles.py の prepare_beginner_game を直す（target は A♠の位置）。
- シャッフルの速度は、最初ゆっくり→だんだん早くする（フロントの入れ替え間隔を
  徐々に短くする）。

## チンチロ（フロントのみ）

- 丼をもっと大きくする（盤面の横幅いっぱいに近い大きさ）。
- サイコロは逆に小さくする（丼に対して現行より小さく）。
- 転がりは、丼の中をサイコロが走り回るようなアニメーションにする
  （丼の内側を複数点経由して跳ね回ってから静止する）。
- 静止したとき上面の目が読みにくいので、静止時の傾きを浅くして、
  上面がはっきり見えるようにする。目は大きく濃くのまま。
- 役名の表示: 通常役は「○の役」ではなく「○の目」に直す（1〜6すべて）。
  ピンゾロ／ゾロ目／シゴロ／ヒフミ／目なしは現行のまま。
