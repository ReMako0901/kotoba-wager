# 2026-11-27 盤面第2弾（ユーザー実機FB、スクショ3枚付き）

対象は frontend/src/games/ のスロット／ブラックジャック／バカラのみ。
バックエンドのルール・確率は変更しない（BJの親は17以上スタンド済み、
バカラの3枚目ルールも実装済みであることを確認済み。辻褄はフロントの見せ方で合わせる）。

## スロット

- 絵柄の下の「待機」表示を消す。レバーの「稼働中」表示も消す（「引く」だけ）。
- 右上の説明文（「右脇の引き手を引いて…」「回転している窓の留め金を…」）を消す。
- 回転の表現を作り替える。現行は絵柄が上にカクカクしているだけで速く見えない。
  絵柄が下へ速く流れているように見せる: 絵柄の帯が下方向へ高速で流れ、
  縦方向のモーションブラー／縦線（ストリーク）で速度を表現する。
- 止める操作では、流れがイージングで滑らかに減速して最終絵柄に着地する
  （急停止しない）。3リールとも同じ作りにする。
- 「止める」ボタンはリールの枠の外へ出し、丸いボタンにする（枠の下に3つ横並び）。
- 盤面全体は、少しだけ世界観から浮く「ラスベガスのスロットマシン」寄りにする。
  金色の縁取り、丸いボタン、レバーの玉など機械らしさを足す。ただしやりすぎない
  （ページ＝手帳の世界は保ち、機械だけが少し浮く程度）。

## ブラックジャック

- 大枠は現行のまま。配り始めに、カードが1枚ずつ配られるアニメーションを入れる
  （あなた→アノマ→あなた→アノマの順）。
- アノマの手札は最初2枚（1枚は表、1枚は伏せ）。現行のように最初から
  4枚分の枠を見せない。追加のカードは進行に合わせてその都度足す。
- 勝負（スタンド）後、アノマの伏せ札が左から1枚ずつめくれていき、右上の合計が
  その都度増えていく見せ方にする。親が引く追加カードも1枚ずつ現れて合計に足す。
  親は17以上で止まる一般ルール（バックエンド実装済み。見せ方を合わせる）。
- あなたの追加カード（ヒット）も配られるアニメーションで1枚ずつ足す。

## バカラ

- 絞り（スクイーズ）を作り替える。現行は一方向から開くだけで意味が薄い。
  **上下左右のどの端からでも絞れる**ようにし、**開けたり閉めたり**（可逆）できる
  ようにする。十分に開いたら表になる（現行の確定条件は維持してよい）。
- 絞り画面の無駄を減らす: 説明文（「端をドラッグまたは矢印キーでめくる」）と
  パーセント表示は消す。「表にする」ボタンも消し、絞り切ることで表にする。
  そのぶんカードを大きくする。
- カードは最初2枚ずつ。3枚目はルールで必要になった時点で足す（現行の進行に合わせる）。
