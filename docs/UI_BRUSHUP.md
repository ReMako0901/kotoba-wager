# UIブラッシュアップ仕様（自律改善ラウンド）

目的：ゲーム全体の見た目・動き・触り心地の質を、持てる力の全てで引き上げる。
配置の前提（ディーラー設計）は維持しつつ、素材感・光と影・タイポグラフィ・
余白・モーション・部品の作り込みを全画面で底上げする。「なんとなく安い」を潰す。

## 絶対に変えないもの（ゲームルールと確定事項）

- 進行順序（報酬→言葉選択→ギャンブル選択→プレイ→結果）、確率・強さ・抽選・保存・API・バックエンド
- 原稿の文法：32pxマス、縦書き10行、連続詰め、横スクロールのみ、角の斜めドラッグめくり
- プレイヤーが全てのギャンブルを自分で操作する（自動進行タイマー禁止）
- 勝率・強さ・増減説明・遊び方・賭け/報酬の recap・ボタン下の状態文を表示しない（メタ情報は永遠に非表示）
- アノマ常時表示＋全場面で台詞（シーンプールと確定台詞の優先順位は現行のまま）。表情プールも現行のまま
- **顔の不可侵**：どの画面でも紙・盤面・札・ボタンが顔（目元〜顎、顔幅）にかからない
- **肖像にぼかしを入れない**（2026-11-18 ユーザー確定。全状態で鮮明に）
- 異常（uncanny）と怒り系の表情は使わない
- つづき機能なし。ページスクロールなし（360×640 / 393×681 / 390×844 で確認）
- ステージは最大480px・全高・中央寄せ。台詞プレートは金の名札付き濃色プレート（現行の格を落とさない）
- 口パク・瞬き・呼吸のアニメーションは維持する

## 質の目標（全画面共通）

- 素材感：卓のフェルトに織り目と vignette、木枠レールに木目と面取り、金具は真鍮のグラデーションと影
- 光：画面全体で光源方向を統一し、物には接地影、紙には卓からの浮き上がり
- タイポグラフィ：見出し・本文・数字の階層を締める。賭け数のライト、版数タブなどの小物も作り込む
- モーション：配る・めくる・止まる・開くの物理感。stagger と spring を要所に。
  prefers-reduced-motion では全てフェードに落とす
- 操作感：押下の沈み込み、選択の確定感、フォーカスリングの見え方
- 細部の統一：角丸・影・縁取りの言語を画面間で揃える

## 画面ごとの重点

- タイトル：表題紙の格を上げる（箔押し感、罫、余白）。はじめるの存在感
- 物語選択：本の背・表紙の作り込み、ホバー/押下で「手に取る」感じ
- 報酬選択：3枚のカードの質（裏面の模様、表の箔、選んだときの動き）
- 言葉選択：原稿が卓の主役。賭け語の朱線、選択時の沈みと色、数のライト
- ギャンブル選択：種目札をカジノのプラークのように
- ジャンケン：両者の手の見せ方、勝負の間
- カード当て：配札の動き、裏面の模様、めくりの物理感
- サイコロ：トレイの質感、賽の転がりと影、目の読みやすさ
- スロット：筐体の作り込み（窓・レバー・ランプ・STOPの手応え）。一番安く見えやすいので重点
- ブラックジャック：ディーラー配置の格。カードの配布順の見せ方、点数表示の置き方（メタ表示は禁止のまま）
- バカラ：両手の配布、スクイーズの角めくり、賭け先の表示
- 生成待ち：現行のスピナー＋インクのシマー（紙の形は使わない）
- 結果：判子の押し感、粉・喪失タグ、差分ハイライトの読みやすさ、原稿の重なり
- 到達・終了・延長：儀式感。台詞プレートが主役になる見せ方
- 履歴・遊び方・入力ノート等のオブジェクト：卓上の物としての統一感

## 進め方

- 実装は作業ツリーへ。コミットはしない（Muse が検証してから行う）
- 既存テストを壊さない。表示文言の追加はしない（台詞・ボタン名・数字のみの現行方針）
- docs/CHANGELOG.md に変更点を追記する
- 検証（テスト・ビルド・撮影）は Muse 側で行うので、サンドボックスで繰り返し試行しない
