# UI大胆化：第2ラウンド

ユーザーの評価（2026-11-18）：第1ラウンドの全面改修は
「まあ良くなった。でも既存のものを守りすぎている」。
現行版は git に残っているので失う心配はない。既存の配置に
とらわれず、大胆で独創的なものを出すこと。

## 今回解除するもの（前回守らせた構成の前提）

- ステージの位置・大きさ・形（上部の帯である必要はない。
  大きく出しても、重ねても、画面ごとに変えてもよい）
- 固定フレーム、ナビ行／メタ行／アクションバーの配置
- 画面の遷移と見せ方、モーダルの形（全画面でもよい）
- タイトル画面・物語選び・ギャンブル画面の構成そのもの
- 前回の装丁（表題紙・背表紙・欄外など）の踏襲義務。
  良いと思えば残し、邪魔なら捨てる

## 進め方

- 画面構成のコンセプト自体を新しく1つ立てて、全体を
  それで貫くこと。「前回の少し大胆版」のような折衷は
  禁止。一番大胆な案を選ぶ
- 原稿用紙とアノマが主役であることは変わらない。
  ただし「どう主役に見せるか」は自由

## 残すもの（ゲームのルールであって配置ではない）

- 流れの順序：報酬3択→言葉選択→ギャンブル選択→
  ギャンブル開始→結果反映
- 原稿用紙そのものの文法：縦書き、32pxマス、10行固定、
  横スクロールののみ、文字は先頭から連続、結果は最初の
  変化箇所が文脈ごと見える、めくりは角つかみの斜めドラッグ
- 賭ける言葉はどれも等価な1個。勝率・強さ・変化量などの
  メタ情報や説明文・状態文を表示しない
- アノマがいて、全場面で喋る。台詞データ（確定台詞・
  場面別プール）と表情プール・クロスフェード等の仕組みは
  再利用するが、見せ方は自由
- ギャンブルは全てプレイヤー本人が操作（自動進行なし）
- 「つづき」は無いまま。バックエンドとAPI契約、確率・
  抽選・保存は変更しない
- スマホ縦画面が主対象

## テストについて

構造に依存する既存テストは、構成の変更に合わせて
書き換えてよい。ただし不変条件の確認（流れの順序、
メタ情報を出さない、つづき不在、アノマの台詞・表情の
仕組みが生きていること）は落とさない。
