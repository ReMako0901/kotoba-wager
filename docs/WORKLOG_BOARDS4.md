## 作業ログ

### 共通・結果表示

- `FreshGamble.tsx` に `OutcomeBanner` を追加。`OutcomeSlip` の丸判子
  （`.folio-wax-seal` / `.folio-seal-ring`）を全種目から削除し、盤面中央に
  「勝利」「敗北」「引き分け」を大きく出すようにした。CSS は
  `games.css` の `.folio-outcome-banner`。結果反映ボタンがある間は表示が残る。
- あいこ・同点は、じゃんけんとチンチロでも中央に大きく出す。次の操作を
  妨げないよう `pointer-events: none`、短いフェードで消える `is-transient`。
  バカラの引き分け（次ラウンドあり）は次へ進むボタンがあるため消さない。
- 結果反映後の生成待ちは、`OutcomeSlip` 内の spinner を廃止。
  `.folio-generation-wait` として中央揃えのインク線 shimmer + 静かな点滅に変更。
  `GenerationSkeleton` コンポーネント自体（別用途）は変更していない。

### 演出時間

- じゃんけん: 掛け声 380→530ms、ポップ 220/180→300/250ms。
- チンチロ: 転がり・回転 1.3→1.8s（reduced motion は従来の短いフェード）。
- カード当て: シャッフル開始 380→520ms、入れ替え間隔 570〜250→790〜350ms 相当、
  終了待ち 280→390ms。
- スロット: 流れ回転 210→290ms、停止減速 640→900ms、レバー 180→250ms。
  レバーを引いてから回り始める 220ms は操作反応なので据え置き。
  仕様内で「スロットのアニメーションは現行で良い」と「全種目共通で
  スロットの回転と減速も遅くする」が食い違うため、意匠・流れは現行のまま、
  全種目共通の時間延長を優先して約1.4倍にした（スロット節の「次だけ直す」は
  文字・見出し・図柄サイズの指定と解釈）。
- ブラックジャック: 配布・めくり間隔 350→480ms、配布/めくり CSS 300→420ms。
- バカラの絞りは指のドラッグに直結するため、遅延を入れず操作反応を優先した。
  覆い紙の transition 70ms はそのまま。ここは仕様の「待たされ感が出る箇所は
  worker の判断」に該当と判断。
- 結果スリップ出現 240→330ms。reduced motion の短いフェードは維持。
