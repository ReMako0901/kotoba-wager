# オープニング演出（2026-11-27）
指定仕様と既存実装を確認。タイトルの暗転、地の文、肖像登場、台詞、左上への縮小を順番に実装する。撮影は Muse 担当。

暗転が終わるまでタイトルを背面に保ち、演出中は背面を操作対象から外した。台詞は既存のタイプライターを共用し、表示途中のタップで全文表示、次のタップで行送り。最終行の縮小後またはスキップ時に候補を取得し、失敗時は再試行できる。

旧テストは「開始直後から上段に最初の台詞」「大きな次へボタン」と仮定していたため、地の文が1行ずつ揃い、肖像の登場後に初めて台詞が出ること、7行の手送り、縮小後の完了、暗転中のスキップを確認する形に更新した。
