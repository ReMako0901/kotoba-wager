# UI再設計（第4ラウンド）：アノマはディーラー、画面は対面の卓

第3ラウンド（アノマ全面＋原稿は手元の物）へのユーザーの
実プレイ評価（2026-11-18、デスクトップ幅のスクショ付き）：

- 顔が原稿で見えない。これでは全面にした意味がない
- レイアウトが崩れている（デスクトップ幅で特に）
- 背景がボケていないので、前景と背景が混ざって意味が
  分からなくなる
- スロットなどギャンブルの盤面が前と変わっていない
- 結論：アノマがディーラーになるよう設計を見直すこと

## コンセプト（固定）

**アノマは卓の向こう側に座るディーラー。画面は対面の卓。**

- 画面の上部は彼女の領域。顔（目・鼻・口）はどの画面でも
  常に全部見える。いかなる物も顔に被らない
- 画面の下部は卓。原稿・札・賽・盤は全部、卓の上に
  置かれた物として出す。彼女は卓の向こうからそれらを
  配り、扱う
- 彼女の台詞は卓の手前縁や彼女の肩口など、顔にかからない
  位置の札に出す

## 絶対のルール

1. **顔の不可侵**：顔の範囲（目の高さから顎まで、顔の幅）
   には、原稿・盤面・台詞札・ボタン・タグの一切を重ねない。
   全画面・全状態で守る
2. **卓への収納**：操作と表示の物は全部、卓の領域
   （画面下部およそ54%）の中に収める。卓には面と縁を
   持たせ、「物の置き場」として読めるようにする
3. **ボケによる奥行き**：卓の物が主役の場面では、彼女の
   レイヤーに弱いボケ（2〜3px）と僅かな減光をかけ、前景が
   即座に読めるようにする。彼女が主役の場面（タイトル、
   到着、エンディング、反応の瞬間）ではボケを外す。
   ボケの付け外しはアニメーションでつなぐ
4. **幅の固定**：ステージは最大幅480px・全高の柱として
   中央に置き、外側は暗い地で埋める。デスクトップ幅でも
   スマホ幅でも構成は同一。要素を画面幅いっぱいに
   引き伸ばさない
5. モーダル被せ、ステージ帯、固定バーは引き続き禁止

## 画面ごと

- **タイトル**：顔の領域いっぱいに彼女。タイトルの札と
  「はじめる」「遊び方」は卓の上に置く。「はじめる」は
  1行に収める（第3ラウンドで2行に折れた欠陥の修正）
- **物語選び**：本は卓の上に配られた物として並べる。
  リストのスクロールは卓の領域の中だけ
- **報酬選び**：彼女が卓に配った3枚の札として出す
- **言葉選び**：原稿用紙は卓の上、手前に置かれた実物の紙。
  彼女の顔は卓の線より上に全部見える。報酬の札・数・
  操作は紙の手前縁に沿う小物として置く
- **ギャンブル選び**：種目札は卓の上の札。初心者／上級者
  の切り替えも卓の上の物として置く。ダイアログで画面を
  覆わない
- **ギャンブル（各種目をディーラー形式で作り直す。
  旧盤面の意匠流用は禁止）**：
  - じゃんけん：卓を挟んで彼女の手とこちらの手が出る
  - カード当て：彼女が卓に伏せ札を3枚配り、こちらが
    選んで彼女がめくる
  - 一発サイコロ：卓の上の賽子と受け皿。こちらが振る
  - スロット：卓の上に立つ小型のスロットマシンという
    物にする。レバー／ボタンはこちらの操作、窓の中に
    リール。旧盤面の流用は不可
  - ブラックジャック：彼女がディーラーそのもの。
    彼女側の手札は卓の向こう縁、こちら側は手前縁
  - バカラ：卓に配られた2つの手。絞りは卓の上の札の
    角めくり（既存の角めくり表現を卓上で使う）
- **生成中**：卓の上の原稿に変化が起きる。彼女は見ている
- **結果**：新しい原稿は卓の上。勝敗の印は紙に押す。
  失った言葉の粉は卓と紙に残る。差分の切り替えは紙の縁
- **到着・脱出選択・エンディング**：彼女の場面。ボケを
  外して彼女に焦点を戻す。選択は卓の上の2枚の札

## 口パク（第4ラウンドで追加）

ユーザーの指摘：顔が大きいのに口が動かないと違和感がある。
台詞が出ている間、彼女の口が動くこと。

- 素材：各表情に「口を開けて喋っている途中」の版を追加する
  （Muse 側で生成し、`frontend/public/anoma/` に
  `<表情id>-talk.webp` として置く。無い表情はパクなしで
  フォールバック）
- 動き：台詞が差し替わった瞬間から、その台詞の長さに
  応じた時間（目安 500ms＋1文字70ms、上限約2.8秒）、
  現在の表情と talk 版を約160ms間隔で交互に表示する。
  台詞が無い／終われば止まる
- 瞬き・呼吸（揺れ）とは独立に共存させる。瞬きが割り込む
  瞬間に口が閉じて見えるのは自然なので許容する
- prefers-reduced-motion では口パクを無効化する

## 不変条件（これまで通り）

- 流れの順序（報酬3択→言葉選択→ギャンブル選択→
  ギャンブル開始→結果反映）
- 原稿の文法：縦書き、32pxマス、10行固定、横スクロール
  のみ、連続詰め、結果は最初の変化箇所が文脈ごと見える
  初期位置、めくりはシート自体の角つかみ斜めドラッグ
  （卓の上の紙でも同じ）
- 賭ける言葉は等価な1個。勝率・強さ・変化量などの
  メタ情報、説明文、状態文は表示しない
- アノマは全場面で喋る。台詞データ（確定台詞＋場面別
  プール、優先順位）と表情プール、異常顔の抑制
  （strength≥8 または喪失≥3 のみ）はそのまま
- ギャンブルは全てプレイヤー本人が操作（自動進行なし）
- 「つづき」は無いまま。確率・抽選・保存・バックエンド・
  API契約は変更しない
- スマホ縦（360×640）でページスクロールなし

## 検証で落とさないこと

- 全ギャンブル画面（6種目＋初心者側）がディーラー形式に
  なっていること。1画面でも旧盤面の流用があれば未完
- 全画面で顔に物が被っていないこと
- デスクトップ幅（1280×800）で構成が崩れないこと
