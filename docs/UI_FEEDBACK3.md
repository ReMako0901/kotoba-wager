# アノマ常時発話：場面別セリフプール

ユーザーの要望（2026-11-18）：アノマは常に喋っていてほしい。
どの場面でもステージの台詞を空白にしない。場面ごとに多数の
台詞を用意し、ランダムに表示する。台詞はこの文書が正本で、
scenario.ts の結果反応とは別に「場面セリフ」として持つ。

## 進め方

- 場面キーごとにプールから1行を選んでステージへ出す。
  場面が変わるたびに選び直す。再描画では変えない
- 同じ場面で直前と同じ行は続けて出さない
- 表情も場面ごとの候補から一緒に選ぶ
- 既存の台詞（オープニング、結果反応、到達・脱出・エンディング）
  はそのまま優先し、このプールで上書きしない

## 場面と優先順位（ゲーム画面内）

モーダル表示中 ＞ ギャンブル中 ＞ 生成・処理中 ＞ 言葉選び。
物語の到達・脱出の判断画面とエンディングは既存の発行が優先。

| 場面キー | いつ | 表情候補 |
| --- | --- | --- |
| title | タイトル画面 | normal / smile / composed |
| storySelect | 物語を選ぶ画面 | normal / composed / smile |
| rewardSelect | 報酬モーダル表示中 | smile / taunt / composed |
| wordSelect0 | 言葉選び・0個 | normal / composed |
| wordSelectPartial | 言葉選び・途中 | smile / giggle |
| wordSelectReady | 言葉選び・揃った | smile / wink / taunt |
| gambleSelect | ギャンブル選択モーダル | taunt / composed / smile |
| gamblePlay:<種目> | ギャンブル中 | taunt / composed |
| generating | 生成・処理の待ち時間 | normal / deadpan / composed |

ギャンブル中の種目は janken / card / dice / slot / blackjack /
baccarat。種目別のプールが無い場合は gamblePlay 共通を使う
（初心者モードの種目も同じプールを引く）。

## 台詞プール

### title
- あら、来たのね。待っていたわ。
- 今日はどの物語を賭けるのかしら。
- 言葉の用意はいい？　始めるわよ。
- ここでは物語が、そのまま賭け金になるの。
- ふふ、逃げるなら今のうちよ。
- あんたの言葉、今日は幾つ残るかしらね。
- 退屈していたところよ。よく来たわね。
- 物語の扉は開いているわ。どうぞ。

### storySelect
- どの物語にする？　運命は自分で選ぶものよ。
- 百を超える物語があるわ。迷うのも楽しいでしょう。
- 最初の言葉が、その物語の全てを決めるの。
- 気になる題名があったら、それが縁というものよ。
- 短い物語ほど、言葉の一つが重いの。
- さあ、選んで。あんたの書きたい物語を。
- どれも誰かの大事な言葉でできているわ。
- 自分で書いた物語を持ち込むのも、歓迎するわ。

### rewardSelect
- 何が欲しい？　欲しいものには、代価が要るの。
- 大きな望みには、大きな賭けが要るわ。
- 選ぶのはあんた。後悔の面倒は見ないけど。
- ふふ、欲張りな目をしているわね。
- 一つだけよ。欲張ると、物語が痩せてしまう。
- その望み、言葉幾つ分の重さかしら。

### wordSelect0
- 赤い線の言葉が、あんたを待っているわ。
- どの言葉を手放せる？　よく見て選んで。
- 言葉は一つずつ、静かに選ぶものよ。
- その物語の、大事な言葉はどれかしら。
- 迷う時間も嫌いじゃないわ。急がないで。
- 軽い言葉ほど、失くすと響くのよ。
- さあ、指先で示して。あんたの覚悟を。
- 全部は賭けられないわ。選ぶことが賭けなの。
- その言葉、本当にいらない？　よく考えて。
- 数えるのは私の仕事。選ぶのはあんたの仕事。

### wordSelectPartial
- いい目をしているわ。その調子。
- あと少し。物語がざわついてきたわね。
- その言葉を選ぶのね。ふふ、面白い。
- 揃うまでの間が、一番どきどきするでしょう？
- 惜しくなってきた？　それが言葉の重さよ。
- あと少しで、私と勝負よ。

### wordSelectReady
- 揃ったわね。では、始めましょう。
- 覚悟は決まったようね。いい顔よ。
- さあ、私のところへいらっしゃい。
- その言葉たち、預かったわ。大事に賭けてね。
- ふふ、震えていない？　大丈夫、すぐ終わるわ。
- 勝負の時間よ。逃げ道は、もうないわ。

### gambleSelect
- どれがいいでしょうね。ふふ。
- 運に任せる？　腕に任せる？　選ぶのも賭けよ。
- どの勝負も、私が相手よ。手加減はしないわ。
- 迷うなら、直感を信じなさい。
- 大きく変わる勝負は、危ない香りがするわね。
- 静かな勝負ほど、読み合いになるの。
- さあ、選んで。あんたの物語が懸かっているわ。
- どれを選んでも、結果は私が見届けるわ。
- 運命の選び方にも、性格が出るのよ。
- 一つに決めて。迷いは賭けの味方をしないわ。

### gamblePlay（共通）
- さあ、見せて。あんたの運を。
- 結果は、もう決まっているのかもしれないわね。
- その手つき、悪くないわ。
- どきどきするでしょう？　私は慣れているけど。
- 目を逸らしたら負けよ。最後まで見届けて。
- ふふ、その顔が見たかったの。

### gamblePlay:janken
- 最初はグー、よ。読めるかしら、私の手が。
- あいこは嫌いじゃないわ。長く遊べるもの。
- 手は正直よ。あんたの迷いが出るわ。
- 三つの手、無限の読み合いね。
- さあ、出して。容赦はしないわ。

### gamblePlay:card
- 一枚選んで。裏側は、私だけが見ているわ。
- そのカードでいいの？　ふふ、変えてもいいのよ。
- 目移りする子は、よく外すわ。
- 当たりは一枚だけ。残りは全部、私のもの。
- 指先が震えているわよ。可愛いわね。

### gamblePlay:dice
- 一振りで決まるの。潔いでしょう。
- 目は転がる間だけ自由よ。
- 大きな目が出るといいわね。私のためじゃなく。
- サイコロは嘘をつかないわ。人は、つくけど。
- さあ、転がして。運命の音を聞かせて。

### gamblePlay:slot
- リールは運命の形をしているの。
- 止める指先に、全部懸かっているわ。
- 揃う瞬間が一番きれいなの。知っているでしょう。
- あと一つ、が一番危ないのよ。
- 回して。物語が目まぐるしく変わるわ。

### gamblePlay:blackjack
- もう一枚引く？　欲は深いわね。
- 数字の読み合い、嫌いじゃないわ。
- 私の手は見えないわ。想像で補いなさい。
- 止まる勇気も、賭けのうちよ。
- 二十一に近い方が勝ち。単純で、残酷ね。

### gamblePlay:baccarat
- 絞る時間は、あんたのものよ。ゆっくりどうぞ。
- カードの端から、運命が覗いているわ。
- どちらに賭ける？　空気を読むのも実力よ。
- めくる瞬間の顔、私は見逃さないわ。
- 静かに、丁寧に。儀式のようにね。

### generating
- 物語を編み直しているわ。少し待って。
- 言葉が並び替わる音がするでしょう。
- 新しい物語は、生まれる時に少し震えるの。
- 待つ時間も、賭けの代価のうちよ。
- どんな姿になるかしら。私も楽しみだわ。
- ページの向こうで、言葉たちが騒いでいるわ。
- もうすぐよ。目を離さないで。
- 静かに。物語が息を整えているわ。

## 含まないもの

確率・強さ・抽選・保存・既存台詞データの変更、バックエンドの
変更。ギャンブルの自動進行は入れない。
