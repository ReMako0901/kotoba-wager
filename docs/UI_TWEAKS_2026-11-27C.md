# 実プレイFB一括対応（2026-11-27 第5弾）

ユーザーの実プレイ所見（スクショ付き）への対応。文言・確率・勝敗判定は変えない。

## 1. 深掘りを具体化する（質問インタビュー）

- 現行の「もう少しだけ、教えてくれる？」は抽象的で答えられない、と却下された。
- 深掘りは質問ごとに具体的な聞き返しにする。sceneDialogue の interviewDialogue に
  質問と対の followup を持たせる:
  - 今日あったこと → 「たとえば、どこで？ 誰といたの？」
  - どこからどうやって来た → 「何に乗って来たの？ 途中で何か見えた？」
  - 今の気分 → 「体は元気？ 眠い、とか、わくわく、とか」
  - 好きなもの → 「たとえば、最近いちばん楽しかったのは？」
  - 今日食べたもの → 「どこで食べたの？ 誰かと一緒だった？」
  - 最近気になっていること → 「それ、いつから気になってるの？」
  - 行ってみたい場所 → 「そこへ行ったら、何をしたい？」
- 発火条件を締める: 回答が5文字以下のときだけ（現行は10文字未満で出過ぎ）。
  名前の問いに出さないのは現行通り。

## 2. 生成文の賭けられる言葉を増やす（バックエンド story_generation）

- 生成文は賭け可能単位数 ≥6 を合格条件にする（現行 ≥3）。
- プロンプトに「具体的な物・人・場所・食べ物などの名詞を6つ以上入れる」を明記。
  再生成プロンプトは8つ以上に強める。本文20〜100字は維持。
- テストの閾値も追随させる。

## 3. タイトル画面

- 「はじめる」ボタンを横中央に置く。
- 表紙（革背景）の上のアノマの台詞が薄くて読めない。台詞の文字色を
  通常のインク色にして読めるようにする（板の意匠はそのまま）。

## 4. オープニングの地の文はタップ送り

- 地の文3行は自動で順に出さず、画面タップごとに次の1行が出る。
  最後の行の次のタップでアノマ登場へ進む。スキップは現行通り。

## 5. 全体的にテンポを遅く

- 各盤面の演出タイミングを全体に約1.3倍へ（じゃんけんの掛け声、
  チンチロの転がり、BJの配布とめくり、スロット、カード当てのシャッフル）。
  何が起きているか追える速さにする。バカラの絞りは操作連動なので対象外。

## 6. じゃんけんの見せ方

- プレイヤーが札を選んだら、選ばなかった札は消える（フェード/縮小）。
- 掛け声「じゃん→けん→ぽん」（遅く）→ アノマの札がアノマ側（上側）から
  出てくる → 中央に勝敗バナー。あいこは現行通り。

## 7. 役名を中央に大きく出す

- チンチロ: 両者の役が確定した瞬間、その役名（ピンゾロ/ゾロ目/シゴロ/
  ○の目/ヒフミ/目なし）を盤面中央に大きく一拍表示する（アノマの役→
  プレイヤーの役の順）。その後に勝敗バナー。
- ブラックジャック: ナチュラル（最初の2枚で21）のとき「ブラックジャック！」
  を中央に大きく表示する（プレイヤー・アノマ双方）。その後に通常の進行/勝敗。

## 8. 左端の縦タブを消す

- 全盤面の左端にある種目名の縦タブ（耳）を削除する。

## 9. バカラのカードと絞りの再建

- カードは純正のトランプ風に戻すが、数字・ランクの表示は一切出さない
  （四隅のインデックスは空白。スートの模様だけで構成し、絞る前に
  点数が読めないようにする）。
- 「下1桁: n」の合計表示は、その手が完全に開くまで出さない。
- 絞りの挙動を作り直す: 端からのドラッグに滑らかに追随してめくれ、
  めくれた分だけ表面（模様）が見える。影と反りで「めくれている」ことが
  分かるようにする。離すと戻る可逆性は維持。75%で確定開示も維持。
- BJとカード当てのカードは従来通りランク表示あり（バカラだけ隠す）。
