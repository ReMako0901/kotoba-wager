# レイアウト根本見直し：視線移動の最小化と、つづき廃止

ユーザーの実プレイ所感（2026-11-18）：「今のUIは視線移動が
カス」。現行画面をスマホ幅で撮影して確認した問題と、組み直し
の方針。あわせて「つづき」機能を廃止する（ユーザー判断：
つづきからやることはない）。

## 現行の問題（実測）

- 上部だけで約164px（ナビ約48px＋ステージ116px）を使い、
  原稿用紙と操作部が下へ押し出される。小さい画面では
  スクロールが発生する
- 言葉選び画面に「今回ねらうもの」の大きな箱があり、
  その情報は下部のドックと二重。目は 箱→原稿→ドック と
  大きく往復する
- 選んだ個数の確認がドックまで行かないとできず、タップ
  する原稿から遠い
- 結果画面も 版の表示・シート見出し・原稿・「どこが
  変わった？」が縦に散らばり、視線が上下に跳ぶ

## 方針：固定フレーム＋1本の視線

ゲーム画面は「スクロールするページ」ではなく固定フレーム
にする。上から順に、目と指がこの順でしか動かない並び：

1. **ナビ行（約40px）**：タイトルへ／メニュー。現行より詰める
2. **ステージ（約76px）**：肖像タイルは52pxに縮小し、
  名札と台詞は横に1〜2行。常駐は維持するが場所を食わない
3. **メタ行（約24px、必要な画面だけ）**：章・タイトル、
  結果画面なら版と勝敗を、この1行に全部寄せる
4. **主役エリア（残り全部）**：原稿用紙／ギャンブルの盤面。
  縦方向は中央寄せ。ここが画面の中心で一番大きい
5. **アクションバー（約64px、フレーム下端に固定）**：
  その画面の状態と主ボタンは全部ここ。原稿のすぐ下で
  視線の終点に置く

高さの目安（縦844px想定）：40＋76＋24＋原稿344＋64＋余白で
約570px。縦640pxの画面でもスクロールなしに収める。
横スクロール（原稿の列）は従来どおり。

## 画面別の組み直し

### 言葉選び
- 「今回ねらうもの」の箱は廃止。ねらう報酬はアクション
  バー左端に「心の声・3個 変更」の1行ボタンとして置く
- アクションバー：左＝報酬（変更ボタン）、中＝選んだ個数
  「1 / 3」、右＝クリア（小）。主ボタン「ギャンブルを選ぶ」
  は従来どおり揃ったらモーダルが自動で開くので、バーでは
  再表示用に兼ねる
- 原稿は主役エリアの中央。メタ行は「第N章 タイトル」の1行

### ギャンブル中
- 盤面は主役エリアの中央。確定・次へ進むボタン類は
  アクションバーに寄せ、盤面と離さない

### 結果
- メタ行に「第N版・勝敗」を寄せ、シート自体の見出し箱は
  廃止（紙の上に重ねる小さな表示でも可）
- アクションバー：左＝「どこが変わった？」、右＝主ボタン。
  差分の表示は原稿の位置そのままで切り替える（目の移動なし）
- 失った言葉・粉の情報はメタ行の下の1行に詰める

### タイトル／物語選び
- ステージは同じ компакт 版に統一する
- 物語選びはリストのスクロールのみ（ここは閲覧画面なので可）

## つづき機能の廃止

- タイトル画面の「つづきから」ボタンを削除
- 起動時の自動復元（localStorage のセッションID読み出し）と
  その失敗表示「つづきを確認できませんでした…」を削除
- 選択状態の localStorage 保存（復元用）も削除
- サーバー側のセッション保持と取得 API は、進行中のプレイが
  使うため残す。遊び始めたら最後まで同じ訪問で完結する前提

## 含まないもの

確率・強さ・抽選・保存（進行中セッション）・台詞・表情の
変更、バックエンドの変更、原稿のマス目（32px・10行）と
めくり操作の変更。
