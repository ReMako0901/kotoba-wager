# 更新履歴

日付は作業整理日。親リポジトリと公開専用リポジトリのハッシュは別物。実際のコミット時刻・全差分は各 `git log` を参照。現在仕様はGAME_OVERVIEWとSTATUSを優先する。

## 粉の傾き操作を廃止

- 粒を細かくし、落ちたあとの位置を固定した。

## 列末の小書き仮名と句読点を前の字と組む

- 「島に」の直後に「渡っ」が一マスで入り、次の列は「た」から始まる。読点と句点も、次の列の頭に来る場合は直前の字と同じマスに入る。

## 粉の山とコンパクトな勝利表示

- 端に寄った粒の重なりを減らし、勝利を枠なしの一行に変更。原稿は高さに応じて折り返すため、縦スクロールせず横に送って読める。

## 原稿の中に粉を持ち越す

- 粉を紙の最下段に積もらせ、同じ物語の間は持ち越す。端末の傾きで移動できるようにし、スキップボタンを削除。候補数と傍線を調整。

## 敗北時に粉が積もる演出と傍線の調整

- BJとバカラの点差・変化の強さを画面から外し、隣接する賭け語の傍線を区切った。敗北時の粉は紙の下に積もる。

## 仮タイトル、物語の入力、段階配札

- 不要な説明を外し、物語の候補を最大5件に変更。自作の物語に対応。
- 原稿用紙の罫線を緑にし、段落の字下げと禁則を適用。ゲームを選ぶとそのまま開始する。
- BJにHITとSTANDを追加。バカラは初手2枚から配り、絞り切った札は自動で公開する。

- 上下左右へのドラッグと矢印キーに対応。「バンカーオープン」でバンカーの伏せ札を一括公開。
