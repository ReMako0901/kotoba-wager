# ゲーム概要

## 作るもの

「ギャンブルライティングメーカー(仮称)」。短い文章の中から、プレイヤー自身が失ってもよい／守りたい意味を選び、欲しい表現・出来事と引き換えに賭ける創作ゲーム。現金、換金、現実の賞品はない。

勝てば賭けた意味が残り、選んだ報酬が物語に加わる。負ければ選んだ意味が消え、成立しなくなった依存描写も必要な範囲で変わる。単語を消して穴を作るだけではない。小さな喪失なら小さく、大きな意味の喪失ならその依存範囲まで変わる。

例：「黄色い日傘」の「黄色い」を失っても、日傘や持ち主まで消さない。「代金の」を失っても、配達員・ピザ・注文者まで消さない。人物そのものを失えば、その人物を前提とする出来事まで変わる場合がある。

## 現在の1プレイ

1. 保存済み開始文100件から最大5件を全文表示。リロールするか、20〜100文字の本文を入力して開始できる。
2. 1件を選択。保存済みの区切りと選択可否を読み込み、報酬を準備する。ここではAI呼出0回（APIキー設定の確認自体は行う）。
3. 報酬3択をポップアップで先に選ぶ。
4. 本文の赤い線があることばを、報酬が要求する1個／2個／3個ちょうど選ぶ。どれも同じ重みで、点数計算はしない。
5. 必要なことばがそろったら、ギャンブルを3種類からひとつ選ぶ。
6. ゲームの選択と同時に開始し、サーバーが勝敗・変化の強さ・図柄やカードの順序を一度だけ確定・保存する。
7. リールを止めるかカードをめくる。その裏でGeminiが意味を解釈し、勝敗と強さに沿う編集案を生成する。
8. 演出を終えて反映ボタンを押し、検査済みの本文を読む。生成が失敗した場合は同じ勝敗で補完する。

## ギャンブルと変化の強さ

|ゲーム|決着時の勝率|変化の強さ|
|---|---|---|
|スロット|50%|当たりの内訳：ベル65%（1）、スイカ25%（2）、REG5%（4）、BIG5%（8）。ハズレは2。|
|ブラックジャック|60%|勝っても負けても1。最初は両者2枚、ディーラーは1枚公開。HITで1枚追加し、STAND後はディーラーが17以上で止まる。初手のナチュラルは約1割。開始時に確定した勝敗はどの操作順でも同じ。|
|バカラ|45%|勝敗共通の点差分布：9点20%（10）、7〜8点25%（9）、4〜6点25%（2）、1〜3点30%（1）。|

バカラはプレイヤー側。各配りの5%でタイとなり、同じベットで配り直す。タイ以外では勝ち45%・負け55%なので、配り直し後の最終勝率は45%。タイの手も開始時に用意する。カードの引き方は[Singapore GRAのバカラ規則](https://www.gra.gov.sg/docs/default-source/game-rules/rws/baccarat-games/rws-game-rules---commission-baccarat-v4.pdf)を参照。抽選確率はゲーム独自。

強さは報酬の価格と独立し、勝利ではポジティブ、敗北ではネガティブな展開の度合いを指定する。強さ1は小さな変化、強さ8〜10は物語の行く先を変える展開を狙う。強さの体感はプレイ評価で確認する。

現在は終了回数・エンディングを実装しておらず、繰り返し取引するプロトタイプ。

## コマと価格

「単語」はUI上の意味ある短いまとまり。辞書上の一単語や文法上の文節と常に一致するわけではない。助詞・助動詞を含んでよい（「私の」「晴れた日に」「拍子抜けして」等）。

枠のない接続表現・副詞・一般的な動作は本文に残る。現行の形態素ルールとゲーム用辞書で可否を決め、AIの採点失敗で「？」を付けて選択を塞がない。選べるコマはすべて同じ1個。

別位置の同じ語もそれぞれ1個として選べる。同じIDの二重選択、古い本文版、重なる範囲、不正個数は拒否。意味が同じ選択を後でまとめても支払ったコマ数は変えない。

## 報酬の仮設定

|必要数|序盤|中盤|後半|
|---|---|---|---|
|1個|ちょっと名文|いい感じの空気|ひとことの魔法|
|2個|ラッキーな発見|うれしい知らせ|まさかの正体|
|3個|まさかの出来事|新しい出会い|新しい行き先|

2ラウンドごとに内容の段階が変わり、3段階目で固定。新フローでは編集規模をギャンブル結果の強さで調整する。報酬の要求個数・ラウンド段階とは別の値。選択可能数が不足すると成立する報酬だけを表示し、要求数を勝手に値引きしない。これらの名称・数・数値は正式決定ではない。

## 体験の方針

- 白黒基調、文章が主役。スマートフォン縦画面・タップ前提。
- 報酬を決めてから賭ける語を選ぶ。なるべく1画面で完結し、長い場合は本文領域内でスクロール。
- 短くポップな文章から始める。弱い変化では局所編集を保ち、強い変化では賭けに結びつく大きな転換を許す。
- 自分が望む作品へ変えることが中心。魔女の好みへ最適化するゲームではない。
- 音楽版の「ギャンブルメロディーメーカー」は発想の前史。現在の実装は文章版。
