# A案 作業メモ

2026-11-25。開始時の差分は未追跡の仕様書のみ。最新指示に従い、このツリーで作業する。
原稿と操作の状態機械は維持し、表示の入口から紙面の体裁を交換する。
作業順は共通紙面・各シーン、原稿・盤面、テスト更新、検証記録。最終検証は Muse。

共通レイアウトを肖像＋欄外台詞と本文に分割。目次は導入があれば導入、なければ本文冒頭。旧ヘルプ、結果の喪失説明、履歴の設定一覧を外した。スロットは保存済み図柄名をそのまま活字にする。状態・通信・抽選・表情選択の変更なし。

3つの新CSS（book.css、book-manuscript.css、book-games.css）に切替。旧CSSのimportをコンポーネント側からも撤去。角ドラッグ中の紙面は原稿領域にクリップする。横読みのスクロールは原稿のみ。フォントは既存の自己ホスト明朝を使用。
初回フロントテストは依存不足。隣接する同リポジトリの lockfile 一致を確認し、検証時のみ依存をリンクした。型検査成功。Vite は依存内の .vite-temp が読み取り専用（EROFS）のため停止。再試行せず最終ビルド・実機確認を Muse に引き継ぐ。
