## 2. 言葉選択画面の配置換え（App.tsx）

- 見出し（.game-heading）に、物語タイトルの後ろへ「＞ 報酬名」を続けて表示する。
  例: 「第1章 メダカの引越し ＞ 関係の変化」。報酬が選ばれている間だけ出す（結果画面では出さない）。
- 下部の wager-tabs から、左側の報酬チップ（「報酬名・○個 変更」／「願いを伝える」ボタン）と
  左の個数表示（stake-count）を**削除**する。
- 個数表示は右下に移し、少し大きくする（20px 目安）: 「選択数 / 必要数」。
  「クリア」は個数の左隣に残す（機能は現行のまま）。
- フッター（.page-links）の左下に「‹ 欲しいものを変更」ボタンを置く。
  押すと報酬選択シートが開く（現行の報酬チップと同じ動作）。言葉選択中
  （結果でもギャンブル中でもない状態）のときだけ表示する。取引履歴は右端のまま。
  レイアウトは左右両端寄せにする。

## 3. チンチロの直し（games/FreshGamble.tsx、games.css）

- サイコロが変で目が見にくい、という指摘。サイコロを大きくし（現行の約1.4倍）、
  目（pip）を大きく濃くして、静止時に上面の目がはっきり読めるようにする。
  丼からはみ出さないこと。1の目の赤は維持してよい。
- アノマの手番は自動にする。「アノマが振る」ボタンは廃止。
  彼女の手番になったら、盤面中央に「アノマのターンです」と表示し、
  少し間を置いて自動で手が送信され、振り直し含め全ロールが再生される。
  表示は彼女の演出が終わるまで出す。同点で次の勝負になるときも同じ。
  **二重送信の防止を必ず入れる**（送信済み管理と busy 連動。ポーリング再描画で再送しない）。
- 盤面が上に寄っているので、チンチロ盤面の内容をページ本体の縦中央に寄せる
  （他の種目の盤面は対象外）。

## 4. 結果画面の直し（App.tsx、StoryHistory.tsx）

- 「どこが変わった？」ボタンを削除する。
- 代わりに、結果画面では最新版の差分ハイライトを最初から表示する（切替なし）。
- 紙の右下の角をめくると変更が見れることは、**初回だけ**説明を表示して示す。
  結果画面の紙の右下近くに小さく「右下をめくると、変更が見れる」と出す。
  一度表示したら以後は出さない（localStorage にフラグを残す。キーは内容が分かる名前に）。
- 「次は何をねらう？」ボタンは右寄せにする（result-tabs は右端寄せ）。
