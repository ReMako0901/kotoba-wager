# 2026-11-27 オープニング演出の作り替え（ユーザー指定の staging）

現行の Opening（Anoma.tsx）は、地の文（中央）とアノマのセリフ（右上）が
同時に表示され、どこを読めばいいか分からない。次の staging に作り替える。

## 流れ

1. タイトルで「はじめる」を押すと、画面が暗転する（フェードで黒へ）。
2. 黒い画面に、地の文3行が白い文字で浮かび上がる（1行ずつ、静かに）。
   文は scenario.ts の openingNarration の3行をそのまま使う:
   「目を覚ますと、目の前には真っ白な空間が広がっていた。」
   「そこには、黒髪の女性が一人。」
   「女性はプレイヤーを見つめ、静かに微笑む。」
3. 地の文が出終わると、アノマが画面に収まるくらい大きくアップで現れる
   （中央、バストアップ大。既存の表情画像 normal を使う）。
4. 彼女の胸元あたりにダイアログ枠が出て、scenario.opening のセリフ（7行）を
   1行ずつ表示する。表示は既存のタイプライター方式。タップ（または小さな
   次へ合図）で送る。
5. 全てのセリフが終わったら、アノマが左上の定位置へ縮小して収まり、
   物語選択の画面へ移る。

## 細部

- スキップは小さく控えめに（右下の小さな文字ボタン程度）。全行程で使える。
  現行の大きな secondary ボタンはやめる。
- 「次へ」の大きなボタンもやめる。送りはダイアログのタップで分かる形に
  （小さな ▼ の合図でよい）。
- 地の文の段階では彼女のセリフを出さない。読む場所は常に1つにする。
- アノマの拡大→左上への縮小はアニメーションでつなぐ（瞬間移動させない）。
- 393×681 で収まること。顔の不可侵は拡大時も維持（ダイアログは胸元まで、
  顔には被せない）。
- reduced-motion では浮かび上がり・拡大縮小を短いフェードに落とす。
- オープニングの文・セリフ自体は変更しない（scenario.ts の文言は正）。
