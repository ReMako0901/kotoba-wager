# 印の再修正（2026-11-27）

前回（MARKS2）の仕上がりへの差し戻し。印機能の土台（保護・記録）は
変えず、見せ方と開始条件だけを直す。

## 1. 印の見た目は「傍線の上の小さなマーク」だけ

- 前回の朱枠＋反転＋大きな丸印は廃止する。
- 印付きコマは通常の原稿の見た目のままにし、そのコマの傍線
  （縦書きセルの脇の線）の上端に、小さなおしゃれな印のマーク
  （朱の小さな印章風マーク等）を1つ置くだけにする。
- 色は朱のみ。原稿の静かな見た目を壊さないこと。

## 2. 台詞はダイアログ表示に戻す

- 印つけの場面でも、アノマの提示台詞は他の場面と同じ
  ダイアログ形式（「アノマ」の名前タグ付きの台詞枠）で表示する。
  枠の中にベタ書きのテキストで済ませない。
- 見出し「印をつける」は残してよいが、カウンタ「（0 / 1）」は
  表示しない（削除）。

## 3. 印は必須にする

- 印を1つ付けないとゲームを始められないようにする:
  - 生成文の確認画面: 印が付くまで開始（「はい」）を押せない。
  - 自作文・プリセットの印つけ画面: 印が付くまで
    「これで始める」を押せない。
  - バックエンド側でも、印がちょうど1つ無いセッションでは
    勝負を開始できないよう検証する（開始経路の入口で弾く）。
- 付け替え（別のコマを押すと移る）と解除の操作自体は維持するが、
  解除した状態では開始できない。
