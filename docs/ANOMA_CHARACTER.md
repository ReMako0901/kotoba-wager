# キャラクターデザイン仕様書 Ver.1.0  
## 言葉の魔女「アノマ」 / ANOMA  
## 1. キャラクター概要  
**名前：** アノマ（ANOMA） **異名：** 言葉の魔女 **役割：** ギャンブルゲームの対戦相手・ゲームマスター **外見年齢：** 不詳（成人女性のような成熟した容姿）  
人間を捕らえ、言葉や記憶を賭けさせる謎の女性。  
人間の記憶を弄ぶことを娯楽としており、言葉の個数にしか価値を見いださない。  
美しく上品な容姿を持つ一方、表情や瞳には人間とは異なる不気味さがある。  
魔女という名称は存在の性質を表したものであり、一般的な魔女の衣装や記号は使用しない。  
## 2. 基本ビジュアル  

| 項目  | 仕様                |
| --- | ----------------- |
| 構図  | バストアップ            |
| 画風  | 白黒漫画調＋控えめなドット表現   |
| 色数  | 純白と漆黒の2色のみ        |
| 髪型  | 長く流れる黒髪           |
| 肌   | 白を基調とした表現         |
| 顔立ち | 大人びた、妖艶で整った顔      |
| 目   | 切れ長で印象的な瞳         |
| 表情  | 余裕を感じさせる薄笑い       |
| 衣装  | 黒と白を基調とした上品な衣装    |
| 装飾  | 胸元の名札を重要モチーフとする   |
| 背景  | 白無地、または最小限の原稿用紙表現 |
  
**画風の重要事項**  
* 既存の基準画像の顔立ち、髪、ポーズ、全体の雰囲気を維持する。  
* 黒ベタと白抜きで立体感を表現する。  
* グレーのグラデーションやカラーは使わない。  
* ドット感は輪郭や一部の陰影に限定する。  
* 8bitゲームのような極端なデフォルメは避ける。  
* アニメーション化に適した明瞭な輪郭を維持する。  
## 3. 瞳の特殊演出  
**アノマの瞳には、ゲームの状態に応じて変化する漢字が現れる。**  
**通常時**  
* 片目の瞳にのみ漢字を表示する。  
* もう片方は通常の瞳。  
* 基本文字：「言」  
* 文字が瞳に自然に溶け込むデザインとする。  
**プレイヤーが言葉を獲得した場合**  
以下の文字からランダムに1文字表示。  
**「得」「増」「生」「添」**  
**プレイヤーが言葉を喪失した場合**  
以下の文字からランダムに1文字表示。  
**「失」「欠」「亡」「消」**  
**重大な改変・異常イベント**  
* 両目に文字が出現する。  
* 「歪」「変」「無」「失」「得」などを使用する。  
* 文字が高速に切り替わり、画面がバグったような演出を行う。  
* 通常時とは明確に異なる異常な表情を表現する。  
**特殊イベント**  
脱出・継続などの選択画面では、以下の文字を使用。  
**「続」「賭」「帰」「終」**  
## 4. 名札のデザイン  
胸元に小さな白い名札を配置する。  
**記載文字：アノマ**  
* 黒い文字で明瞭に記載する。  
* 文字の中央を横切る一本の黒い取り消し線を入れる。  
* 線は文字が読める程度の細さにする。  
* 黒い長方形による全面的な塗り潰しは禁止。  
* 名札全体の装飾は控えめにする。  
**意図：** 自らを「アノマ」と名乗りながら、その名前が取り消されているという矛盾を視覚化する。  
## 5. 表情・ポーズ  
基本表情は、プレイヤーを観察して楽しむような微笑み。  
* 視線は正面のプレイヤーに向ける。  
* 口元には小さく余裕のある笑み。  
* 目は冷静で、感情を読み取りにくい。  
* 初期画像と同様、片手を顔の近くに添えるポーズを基本とする。  
* 過度な笑顔、誇張した悪役の表情は避ける。  
## 6. 画像バリエーション  

| 状態   | 瞳           | 表情        |
| ---- | ----------- | --------- |
| 通常   | 片目「言」       | 薄笑い       |
| 言葉獲得 | 片目に獲得系の漢字   | 嬉しそうな微笑み  |
| 言葉喪失 | 片目に喪失系の漢字   | 興味深そうな微笑み |
| 重大改変 | 両目に異常系の漢字   | 不気味な笑顔    |
| 脱出選択 | 片目にイベント系の漢字 | 静かな微笑み    |
  
すべてのバリエーションで顔立ち、髪型、衣装、構図、名札の位置を統一する。  
## 7. アニメーション対応方針  
今後のゲーム実装では、以下の要素を独立して動かせる構造を想定する。  
* 瞬き  
* 口パク  
* 表情の切り替え  
* 瞳の漢字の差し替え  
* 両目の文字の点滅  
* 文字化け・グリッチ演出  
将来的にパーツ分割型アニメーションやスプライトアニメーションに展開できるよう、衣装と髪のシルエットを複雑にしすぎない。  
## 8. 避ける表現  
* 魔女帽子、杖、角などの典型的な魔女記号  
* カラー表現やグレーの多用  
* 極端なデフォルメや幼い容姿  
* 派手なカジノ風装飾  
* 過度なファンタジー装備  
* 大量の浮遊文字や装飾的な魔法陣  
* 瞳の文字が常に両目に出現する表現  
* 名前が読めなくなるほど太い取り消し線  
## 9. 初回修正生成の指示  
既存の基準画像を参考に、キャラクター「アノマ」の通常時バストアップ画像を制作する。  
顔立ち、長い黒髪、妖艶な微笑み、白黒の漫画調、衣装、ポーズは元画像を可能な限り維持する。  
以下の2点を重点的に変更する。  
**変更点1：瞳**  
片目のみに漢字「言」を表示し、反対側の瞳は通常の瞳にする。  
**変更点2：名札**  
胸元の名札に「アノマ」と記載し、その文字の中央を細い一本の黒い横線で取り消す。名前は判読可能な状態を維持する。  
新たな魔女装飾を追加せず、純粋な白と黒のコントラストを保つ。  
**初回生成対象：通常時の基本立ち絵1枚。**
