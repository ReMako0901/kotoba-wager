# 画面遷移アニメーション仕様（C案「手帳」への追加）

ユーザーが2026-11-25、本番採用したC案について「アニメーションが少ない。
全ての画面遷移が滑らかなアニメーションで繋がるようにしたい」と指示。
作業ブランチは motion-c（このツリー）。見た目の世界観（手帳）は変えない。

## 目的

画面が切り替わるたびに、紙の手帳のページをめくるような連続した動きでつなぐ。
瞬間的な切り替え（カット）を主ループから無くす。

## 設計の柱

1. **写真と台詞の欄は画面遷移で動かさない**。アノマの写真・台詞ゾーンは常駐し、
   ページ部分だけが入れ替わる。表情のクロスフェードと口パクは既存のまま。
   台詞の文が変わるときは文字が柔らかくクロスフェードする。
2. **ページの入れ替わりは「めくる／差し替える」動き**。新しい画面は紙が置かれるように
   滑り＋フェードで入り、古い画面は静かに退く。派手な回転は使わない（紙の端が
   わずかに持ち上がる程度の示唆に留める）。
3. **物は置かれる**。報酬のメモ、ギャンブルの盤面の物（札・賽・装置）は、
   ページの上に置かれるように小さなスケール＋フェードで現れる。複数ある物は
   少しずつずらして（スタッガー）出す。
4. **結果への遷移はインクの円形リビール**。生成待ちから結果原稿へは、
   インクが広がるように新しい原稿が現れる。押印の動きは既存を活かす。

## 遷移ごとの指定

- 起動→タイトル：表紙が開くようにフェード＋わずかなスライド。
- タイトル→導入／物語選択：ページめくり（横スライド＋フェード）。
- 物語選択→報酬：3枚のメモが下から順に滑り込む（スタッガー）。
- 報酬→言葉選択：ページめくり。原稿は全体が柔らかく入り、操作列が遅れて現れる。
- 言葉選択→ギャンブル選択シート：シートがページの下端からせり上がる。
  閉じるときは逆に沈む。
- ギャンブル選択→盤面：盤面の物が置かれる動き（柱3）。盤面から戻るときも同様。
- 盤面→生成待ち：フェードで待ち画面へ。待ちのシマー（インクの線）は既存を維持。
- 生成待ち→結果：インクの円形リビール（柱4）。
- 結果→次の報酬／物語選択：ページめくり。
- 到達・終了・履歴・手帳メモ・物語入力フォーム等の副画面：フェード＋小さなスライド。
- 戻る操作（タイトルへ等）では、進むときと逆向きのスライドにする。

## 技術の決め事

- 実装はCSSの transition / animation を中心にし、画面の切り替わりは
  画面キーを持つラッパーのマウントアニメーションで駆動する。
- 時間は200〜450ms。イージングは柔らかい減速（cubic-bezier系）。
- アニメーションは transform と opacity だけを使う。レイアウト寸法を変えない
  （393×681でスクロールなし完結、という既存の検証結果を壊さない）。
- 遷移中も操作は妨げない。連打で状態が壊れないこと（アニメーションは見た目だけ）。
- prefers-reduced-motion では全て短いフェードに落とす（既存の無効化方針と揃える）。
- アニメーションでゲームを進めない。タイマーで画面を進めたり、ギャンブルの
  操作を代行したりしない。きっかけはユーザーの操作とマウントだけ。

## 不変条件（従来どおり）

- ゲームルール・流れ・確率・抽選・保存・バックエンド・APIは無変更。
- 原稿の力学（32px、10行、連続詰め、横スクロールのみ、角ドラッグめくり）無変更。
- メタ情報は表示しない。アノマは常時表示・常時発話。表情プール無変更。
  異常・怒り系は使わない。肖像に blur を使わない。顔を静止UIで覆わない。
- つづき機能は作らない。
