# 2026-11-27  tweaks: 粉砕の粒度と速度／報酬の対話化／呼び方／タイトルへ削除／台詞タイプライタ

ユーザー指示（2026-11-27、実機スクリーンショット付き）。対象は main 最新
（ゲーム部クリーンルーム実装済み）。ゲームのルール・確率・台詞プールの選択方式は変えない。

## 1. 粉砕アニメーションを細かく、ゆっくり、イージングらしく

- 喪失時に文字が砕ける分割を 3×3 から 6×6 に細かくする
  （`Manuscript.tsx` の `animateInk` の divisions。reduced-motion では従来通り 1）。
- 飛行時間は 720ms から約 1500ms へ。`notebook-motion.css` の `loss-to-photo`:
  前半はゆっくり砕けて広がり（ease-out 的）、後半は加速しながら写真へ吸い込まれる
  （ease-in 的）二段のイージングにする。キーフレームの割合と
  animation-timing-function（cubic-bezier）で表現すること。
- 破片の行き先（アノマの写真中心）・発生条件・後片付けは現行のまま。

## 2. 報酬選択をアノマとの対話形式にする

現行は見出し「何を手に入れる？」＋選択肢カードの事務的な画面。次のように変える。

- 報酬シート（App.tsx の SceneObject kind="rewards"）の見出しを、アノマの問いとして
  「何が欲しい？」にする。UI見出しの書体ではなく、台詞として読める見せ方にする
  （名前札「アノマ」＋台詞体の文。枠の世界観＝手帳のページは維持）。
- 選択肢は「願いを伝える札」として見せる。各札は従来通りタイトルと必要個数が本体。
  必要個数は「ことば ○個」という引き換えのメモとして札の端に置く。
- 報酬を開くボタン（wager タブ側、現行「報酬を選ぼう」）の文言を「願いを伝える」に変える。
  選択後の表示（選んだ報酬名＋個数、選んだ個数、クリア）は現行のまま。
- 選択の動作・offer の中身・要求個数の意味は変えない。説明文は足さない。

## 3. 呼び方「あんた」→「あなた」

- `sceneDialogue.ts` 内の「あんた」を全て「あなた」に置き換える（8箇所）。
  ゲーム外の素材ファイル（materials/ 等）は対象外。scenario.ts 側にあれば同様に。

## 4. 「タイトルへ」ボタンを消す

- App.tsx 下部 `.page-links` の「タイトルへ」（title-link）を削除する。
  「取引履歴」は残す。レイアウトは履歴が右端に残る形を維持する。
- 終了画面（StoryProgress）の「タイトルへ戻る」は対象外（残す）。
- returnToTitle が他で使われていなければ、未使用コードを残さない。

## 5. アノマの台詞を左から一文字ずつ表示（タイプライタ）

- 台詞欄（Anoma.tsx の dialogue 表示）で、台詞が左から1文字ずつ現れるようにする。
  間隔は 30〜40ms/字を目安に、読みやすい速度にする。複数行の台詞は行をまたいで
  順に表示する。
- 口パク（speaking）はタイプ表示が終わるまで続ける。既存の長さ比例の上限計算と
  喧嘩にならないよう、speaking の終了はタイプ完了に合わせる。
- スクリーンリーダー向けには全文が読めるようにする（表示側は aria-hidden、
  全文は aria-label か sr-only で提供）。
- prefers-reduced-motion では即時に全文表示する。
- 台詞が切り替わったら最初からタイプし直す。ポーリング等の再描画で
  タイプがやり直しにならないこと（現行の「場面入場時のみ選択」と同じ前提）。
