# 追加指示（2026-11-25、ユーザー）※モーション実装の後に同じブランチで実装する

1. 言葉選択の「ギャンブルを選ぶ」ボタンを削除する。規定数（報酬の要求数）の
   単語を選んだら、自動でギャンブル選択へ遷移する（現行の自動ポップアップを
   正規の経路とし、ボタン経路を無くす）。シートを閉じた場合は、選択を
   変えて規定数に戻したときに再度自動で開く（現行の抑制ロジックを維持）。

2. 負けて単語（の意味）が消える時、その単語が黒いカスになって粉々に砕け、
   破片が左上のアノマ（写真）の方へ飛び、写真に吸い込まれて消える
   アニメーションを付ける（2026-11-25 ユーザー確定：吸い込まれて消える）。
   実装は transform / opacity 中心、reduced-motion ではフェードに落とす。
   ゲームの進行や結果には影響させない（見た目だけ）。
