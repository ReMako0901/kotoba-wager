# 印の再修正 作業メモ

仕様は MARKS3.md。生成文はセッション作成時、自作文・プリセットは作成後に印を確定する。共通の勝負入口で初回抽選前にも検査する。画面は既存の台詞表示を使い、印と賭けの選択を区別する。

印の先頭断片の傍線に5pxの朱の菱形を配置。印選択時の反転とカウンタを除去し、StagePublisher 経由で名前タグ付きの台詞を表示した。生成文「はい」と自作文・プリセット「これで始める」は印が1つのときだけ有効。初回勝負の入口はロック内・抽選前に確認し、途中で印を失った後は継続できる。旧版で空の印を確定した未プレイ原稿も再選択できる。

pnpm 実行ファイルがないため、ロックファイルが一致するメインツリーの node_modules をコピー。フロントテストは repo ルートから実行する。初回の全体検証で、選択できるコマがない既存テスト用原稿が見つかり、その原稿にコマを追加した。
