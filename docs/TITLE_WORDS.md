# タイトル画面に DB の言葉を立体的に散らす（2026-11-27）

タイトル画面（表紙）の背景に、Firestore の generated_stories に
保存された物語から抜いた言葉を、立体的に飛び出して見えるように
散らす。過去のプレイヤーの言葉が漂う、将来の OP 構想の先行実装。

## データ（バックエンド）

- 新規エンドポイント GET /api/title-words:
  generated_stories の各文書の text（final_text があればそちら）を
  既存の解析（賭けられるコマ）で分解し、単語候補を集める。
- 除外フィルタ（必須）:
  - 卑猥な語・誹謗中傷語を含むコマは除外する。NG 語リストは
    バックエンドの定数として持ち、部分一致で判定する
    （最低限、性的な語、侮蔑語、差別的な語の代表例を含める）。
  - 文書単位でも、タイトル・本文に NG 語が含まれる物語は丸ごと除外。
  - プレイヤーの名前（文書の name）は表示しない。名前に一致する
    コマは除外する（置換ではなく除外でよい）。
  - 連絡先らしい文字列・数字列を含むコマは除外（既存の
    コンタクトパターン判定を再利用）。
- 返すのは単語の配列のみ（最大60語程度、重複は除く）。
  物語の本文や名前は返さない。
- 保存が0件・取得失敗のときは空配列を返し、画面は従来どおりになる。

## 表示（フロントエンド）

- 場所はタイトル画面のみ。言葉は背景レイヤーに置き、
  既存要素（アノマの写真・台詞枠・タイトル・はじめるボタン）の
  邪魔をしない: pointer-events は無効、z-index は表紙の
  テキストより後ろ、上部の写真と台詞の帯には重ねない
  （散らす範囲はタイトル周辺から下半分を中心にする）。
- 立体感: 親に perspective を付け、各語に奥行き（translateZ）と
  大きさ・濃さの差を付け、手前の語は大きく濃く、奥の語は
  小さく薄く。ゆっくり漂う/浮き沈みする程度の穏やかな動き。
  革の表紙に金箔や刻印が浮かぶような、落ち着いた色味
  （クリーム〜金系、濃さは控えめ）。
- 語の配置は単語ごとに決定的に（同じ語は毎回だいたい同じ位置）。
- prefers-reduced-motion では動かさず静止表示。
- 言葉が無い場合は何も出さない（従来の表紙のまま）。
