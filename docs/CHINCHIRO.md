# 一発サイコロを「チンチロ」に置き換える（2026-11-27 ユーザー決定）

一発サイコロが分かりにくいというユーザー指摘を受け、アノマと対戦するチンチロに
置き換える。サイコロの転がりは物理風アニメーション（軽量方式。ユーザー選択済み）。
勝敗の確定は従来通りサーバー側。出目はサーバーの確定値と必ず一致させる。

## バックエンド（backend/app/gambles.py、models.py）

- GAMES から dice を外し、初心者枠に chinchiro を入れる:
  `{'id': 'chinchiro', 'name': 'チンチロ', 'tier': 'beginner', 'win_probability': .5, 'description': 'アノマと丼で勝負。役の強さで比べる。'}`
  BEGINNER_GAMES = {'rps', 'card_guess', 'chinchiro'}。models.py の Literal も差し替え。
- 役の判定 `chinchiro_hand(dice)`:
  ピンゾロ(1,1,1) ＞ ゾロ目（3つ同数、point=その数）＞ シゴロ(4,5,6) ＞
  通常役（ペア＋残り1つ、point=残りの目）＞ ヒフミ(1,2,3) ＞ 目なし（上記以外）。
  ランクは (順位, point) で比較できる形にする。
- 手番の進行は play_beginner_game で行う（choice は None のみ許可）:
  1. アノマの手番（game に彼女の確定手が無いときの手）: 3個振りを最大3回まで繰り返し、
     目なしでなければ止まる。3回目も目なしなら目なしが彼女の手になる。
     move = {'side': 'anoma', 'rolls': [[a,b,c], ...], 'yaku': 'pinzoro'|'zorome'|'shigoro'|'normal'|'hifumi'|'menashi', 'point': int|None}。
     game['anoma'] に確定手を保持する。
  2. プレイヤーの手番（以降の手は1回振るごとに1手）:
     move = {'side': 'player', 'roll': [a,b,c], 'yaku': ..., 'point': ..., 'attempt': n}。
     目なしで試行が3回未満なら手番は続く（結果は付かない）。
     手が確定したら彼女の手と比較する:
     - 勝ち/負け → game に outcome / strength / label を設定（既存の形式）。
       strength は勝った側の役で決める: ピンゾロ 8、ゾロ目 6、シゴロ 4、
       通常役は point 6→3、4〜5→2、1〜3→1、ヒフミ・目なしでの勝ちは 1。
     - 同点（同ランク同 point、両者目なしを含む）→ move に 'result': 'tie' を付け、
       彼女の確定手とプレイヤーの試行をリセットして次の勝負に進む（結果は付けない）。
- 両者が同じ分布で振り直しを繰り返すため、決着時の勝率は対称で 50% になる。
  確率を寄せるための細工はしない。
- バックエンドテスト: test_gambles.py の dice テストを chinchiro の役判定と
  手番進行（目なし振り直し、同点の再勝負、勝敗と strength）のテストに置き換える。

## フロントエンド（frontend/src/games/ 配下、types.ts、sceneDialogue.ts）

- DiceGamble を ChinchiroGamble に置き換える。kind 'chinchiro'。
  types.ts の BeginnerKind も差し替え。
- 盤面（手帳の文法で）: 紙の上に置かれた丼（円い器）を主役にする。丼の中に
  サイコロ3個。アノマの確定手は丼の脇の札に役名と出目で残す。プレイヤーの
  試行回数は小さな刻み（タリ）で示す。種目名の耳タグは「チンチロ」。
- サイコロは立体感のある立方体（CSS 3D）で各面に目（pip）を描く。
  物理風アニメーション: 振ると丼の中で約1.3秒、跳ねて回りながら減衰し、
  最後はサーバーの出目が上を向いて静止する。実装手法（rAF の簡易物理でも
  WAAPI のキーフレーム合成でも可）の制約:
  - サイコロが丼の外に出ない
  - 最終的に上を向く面がサーバーの出目と完全一致する
  - 演出は最後まで再生し、スキップ手段は置かない。演出中は次の操作を無効にする
  - prefers-reduced-motion では短いフェードで静止状態を見せる
- 進行（操作は全部プレイヤー）:
  1. 盤面が開いたら「アノマが振る」ボタン（丼タップでも可）→ 彼女の振り直し含め
     全ロールを続けて再生 → 役名札が出る。
  2. 「丼を振る」ボタン → 自分の1回が再生される。目なしで試行が残れば
     「目なし」の小札と「もう一度振る」ボタン。
  3. 手が確定したら比較結果（勝ち/負け/同点）を札で示す。同点なら
     「もう一勝負」ボタンで次の勝負（彼女の手番から）。
  4. 決着したら共通の完了部品（OutcomeSlip＋「この結果を物語へ」）。
- 役名の表示: ピンゾロ／ゾロ目／シゴロ／○の役（通常役は point の数字）／ヒフミ／目なし。
  勝率や役の強さ表などのメタ情報は出さない。ルール説明文も足さない。
- sceneDialogue.ts: キー "gamblePlay:dice" を "gamblePlay:chinchiro" に改名する。
  台詞は「一振りで決まるの。潔いでしょう。」の1行だけ（実態と合わないため）外し、
  残り4行はそのまま使う。外したことは作業メモに明記する。
- dice を前提にしたフロントテストは chinchiro に合わせて更新する。
  ui-layout.test.cjs のサイコロ盤面前提のテストは、目的（手の送信・ポーリング・
  完了ボタンの有効化）が保てる別種目（カード当て等）に置き換えてよい。理由を作業メモへ。
