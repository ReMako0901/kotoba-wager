# 印の仕上げ直し（2026-11-27）

実プレイ所見への対応。対象は印機能（docs/MARKS.md）。

## 1. 印は1個まで

- 上限を3個から1個に変更する（フロントのカウンタ表示・選択制御、
  バックエンドの検証、テストも合わせて）。既に印がある状態で
  別のコマを押したら、印がそちらへ移る形でよい（付け替え可能）。

## 2. 印の見た目を、おしゃれで分かりやすく

- 現在は小さな点にしか見えず、何の印か分からない。
- 朱色の印章（ハンコ）を押したような意匠にする: 印付きコマの
  先頭に小さな朱の丸印（白抜きの「印」の字入り、または同等の
  印章モチーフ）を付け、コマ自体にも朱の枠や下線で
  「印が付いている」と一目で分かるようにする。
- スマホ幅でもはっきり視認できる大きさにする。色は朱のみ、
  既存のデザイン系統（原稿用紙・白黒・差し色は赤）に沿う。

## 3. 印つけパートを区画として示す

- 確認・編集画面（生成文）と印つけ専用画面（自作文・プリセット）の
  どちらでも、印つけが独立したパートだと分かるようにする:
  枠と見出し（例「印をつける」）で区切り、アノマの提示台詞と
  カウンタをその区画の中に入れる。本文の確認とは別の手順だと
  一目で分かること。

## 4. 台詞の修正

- 提示台詞から冒頭の「それでも、」を削除する:
  「本当に変えられたくない記憶には印をつけておくんだよ。
  もっとも、それを賭けるのが楽しいんだけどね」

## 進め方

- 作業メモ docs/WORKLOG_MARKS2.md を随時更新する。
- コミットしない。CHANGELOG / STATUS / CURRENT_INSTRUCTIONS は触らない。
- 既存の不変条件（AGENTS.md）は全て維持する。
