## 既知の問題

1. 分割は品詞・辞書・結合規則。意味ある動詞の取りこぼし、形式名詞の過剰選択、未登録の慣用句の分断が残る。
2. 自由生成に対する区切り精度を測る正解データが未整備。38テストは全体精度の数字ではない。
3. Geminiの意味解釈・文章の自然さ・過去の消失の完全維持は保証できない。
4. 部分編集の原文照合・重複・差分上限で安全停止し、手動再試行が必要な場合がある。
5. 保存済みセッションに分割規則のversionがない。途中のコマを勝手に再分割できない。
6. 無料Renderの保存は永続でない。アカウント・本格的な費用制限・研究データ保存基盤は未整備。
