# Playing card artwork

Byron Knoll's standard deck, from [notpeter/Vector-Playing-Cards](https://github.com/notpeter/Vector-Playing-Cards/tree/861b338eb931d635c442b568071e3829e552f383).
The upstream project releases the artwork into the public domain and offers the WTFPL as an alternative.

The source SVGs are rendered here as 512 × 744 WebP images.
